# Генератор фикстур OptionSale

`OptionSaleOracle.java` использует схему, делегат, двоичный кодировщик и парсер QD ревизии `0ddc0a09779fb61d74cc0b37c6449ff47dcb715f`. Соберите его с соответствующими собранными модулями QD в classpath и вызовите `--help` или `--help=ru`: встроенная справка описывает запуск, профили, выходные файлы и ошибки. Для автономного запуска требуется ещё не существующий выходной каталог. Записи `standard`, `tiny`, `nano` и `field` содержат по восемь наблюдений и четырнадцать отказов при отсутствии обязательного поля. Хеши и результат сравнения часовых поясов приведены в `receipt.json`.
