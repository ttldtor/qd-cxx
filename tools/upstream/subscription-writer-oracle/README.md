# Native subscription parser verification

[Русская версия](README.ru.md). English is authoritative.

This optional developer tool passes bounded synthetic native output through the locked production
Java BinaryQTPParser. It compares actual callbacks and readSubscriptionTime calls with the native
test's independent input expectations. It opens no sockets. The ordinary native build/CTest does
not invoke Java. [Wire/API contract](../../../spec/subscriptions/WRITER.md) and
[capture profile](../../../tests/fixtures/subscriptions/writer/README.md) define the scope.

Requires CMake 3.25+, Git, explicit JDK 8, a clean checkout matching
[upstream.lock](../../../upstream.lock), and trusted prepared production classes/receipt from
[schema preparation](../../schema-export/README.md). Preparation can acquire Maven dependencies;
Verify.cmake does not fetch, build upstream or install anything globally. Ambient JAVA_TOOL_OPTIONS,
_JAVA_OPTIONS and JDK_JAVA_OPTIONS are rejected. Native test setup may separately fetch pinned doctest.

## Reproduction

Run from the repository root. Replace the illustrative installed-tool/checkout paths:

```powershell
cmake -DHELP=ON -P tools/upstream/subscription-writer-oracle/Verify.cmake
cmake -S . -B .work/subscription-tests -DBUILD_TESTING=ON -DORG_TTLDTOR_QDCXX_BUILD_SCHEMA_JSON=OFF
cmake --build .work/subscription-tests --config Release --target qdcxx_subscription_writer_tests
ctest --test-dir .work/subscription-tests -C Release -R '^protocol_subscription_writer$' --output-on-failure
$repo = (Get-Location).Path.Replace('\', '/')
cmake "-DJAVA_HOME=C:/tools/jdk8" "-DUPSTREAM=C:/work/QD-locked" `
  "-DRECEIPT=$repo/.work/schema-export/prepare/classpath-receipt.json" `
  "-DNATIVE=$repo/.work/subscription-tests/subscription-native-captures" `
  "-DRUN=$repo/.work/subscription-java-check" -DMODE=Verify `
  -P tools/upstream/subscription-writer-oracle/Verify.cmake
```

NATIVE must contain native.qtp, expected.tsv and expected-time-reads.tsv generated by the test.
The test writes only its configured build-local capture directory, never committed fixtures.
No new test CLI is introduced; the existing doctest help runs no cases.

JAVA_HOME, UPSTREAM, RECEIPT, NATIVE and RUN are required for work. RUN must be new and separate
from native inputs, upstream and goldens. MODE defaults to Capture: it still verifies both Java
outputs against native input expectations. Verify additionally compares the five artifact files
against EXPECTED, default tests/fixtures/subscriptions/writer/expected.
No mode publishes or changes goldens. No arguments and standalone -DHELP=ON print identical help
without providers/input/work; use this script setting because CMake owns global --help.
Exit 0 is help/success; exit 1 is argument, provenance, compilation, parser or comparison failure.

RUN retains classes, JVM/provider receipts and raw logs. Java compilation is limited to 60 seconds,
parse to 30 seconds, and help probes to 15 seconds. The child heap is 256 MiB; this is not a process
RSS cap. Before/after source/provider/native-input hashes must match. Exact bytes are compared
without normalization, including generated LF metadata and original native binary.

## Direct helper

`java -Xmx256m -cp CLASSPATH qdcxx.oracle.NativeSubscriptionParser --input FILE --output NEW_DIRECTORY`
uses both required options; order may vary. Standalone --help and no arguments produce identical
UTF-8 stdout, empty stderr and exit 0 even without QD providers. Invalid/duplicate arguments exit 3;
I/O, existing output, parser/resource failure and failed help output exit 1. No input or existing
output is overwritten. A failed write can leave partial new files; only exit 0 is successful.

The selected receiver contains Indexed 0 (timed hi/lo/x), Beta 1 (x/y), Alpha 2 (x), all compact int
fields. Only descriptions and six subscription types are accepted. Limits: input 1 MiB, 4096 messages/
tuples/time reads, 64 descriptions, sender IDs 0..65535, 4096 units per symbol and 65536 total.
Unknown records/types, corruption and incomplete EOF fail. The production descriptor parser can
allocate field arrays before validating the complete body; the heap bound is required independently
of the input-byte bound.

observations.tsv records actual message/index/receiver ID/name/symbol/raw time.
Names/symbols are lowercase four-digit UTF-16 hex; empty is an empty cell, not null.
time-reads.tsv records actual protected production reader calls. Both files are UTF-8/LF/no BOM.
The fixed receiver is an oracle fixture, not a general external-scheme loader or complete live client.
