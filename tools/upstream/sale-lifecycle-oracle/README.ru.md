# Oracle жизненного цикла продаж в HISTORY

[English version](README.md). Основная версия — английская.

`SaleLifecycleOracle` офлайн запускает закреплённые делегаты TimeAndSale и OptionSale, дистрибьютор и QDAgent из Java QD. Для каждого события записывает неполный и полный снимки, коррекцию с `TX_PENDING`, отмену сделки, удаление по индексу, усечённый снимок, локальную повторную подписку и новый collector. У OptionSale независимо записываются Index и бизнес-время.

Для захвата передайте путь к новому каталогу. Генератор создаёт два каталога событий с `oracle.tsv`, последовательными сегментами `wire-*.qtp` и потоком `fresh/`. Запуск без параметров и `--help` выводят английскую справку, `--help=ru` — русскую. Просмотр справки не создаёт файлы. Код 0 означает успех. При ненулевом коде произошла ошибка параметров или захвата и часть результатов может остаться на диске.

Воспользуйтесь [командами воспроизведения](README.md#reproduce) для JDK 8 и закреплённой ревизии из [upstream.lock](../../../upstream.lock). Сравните SHA-256 каждого файла по относительному пути в UTC и Pacific/Honolulu. Нумерованные сегменты в каждом каталоге образуют один поток. У `fresh/` отдельный composer и собственное описание записи. Повторная подписка и новый collector в Java проверяются локально. Тест C++ отдельно проверяет TCP-переподключение и квалификацию наблюдения диапазона по текущей эпохе источника.

Генератор читает данные агента после перезапуска и после SNIP. В результатах сохраняются флаги, видимые на каждой границе чтения.
