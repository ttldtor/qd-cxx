# Проверка источников и индексов Order через Java

[English version](README.md). Английский текст имеет приоритет.

`Invoke-Oracle.ps1` вызывает actual production отображения, delegate и методы
значений Order закреплённого Java QD, не переписывая их алгоритмы. Публичный
источник данных, сборка и загрузка SDK не используются. Уже собранные классы
должны соответствовать [upstream.lock](../../../upstream.lock). JDK форматтера
отделён от JDK8 для наблюдений.

`-Help`, запуск без аргументов и `-HelpRu` не требуют рабочих входов и не создают
файлы. Для Capture/Verify нужны `-Upstream`, `-JavaHome`, `-Logger`,
`-RunDirectory`; `-Mode` по умолчанию Verify. RunDirectory — новый каталог внутри
`.work` этого checkout. Capture заменяет только fixture и provenance этого
компонента; Verify сравнивает их без замены. Сохраняются полные UTC-логи,
результаты команд и инвентари production-классов до/после.

```powershell
pwsh -NoProfile -File tools/upstream/order-index-oracle/Invoke-Oracle.ps1 -HelpRu
```

Каждая Java-команда, включая определение версии, ограничена heap128MiB и
таймаутом60 секунд. Останавливается только собственное дерево процесса после
таймаута. Exit0 — успех/справка; exit1 — вход, reference, процесс, таймаут,
provenance или наблюдения не прошли проверку. Сеть и работа с зависимостями не
запускаются.

[Fixture](../../../tests/fixtures/order-index/oracle.tsv) содержит 321 наблюдение
в двух часовых поясах: классификация источников, извлечение/замена битов индекса,
разрешение источника записи, реальные стандартные объявления полей и упаковка
OrderDelegate при приёме, неверные суффиксы и физические int под другими полными
типами. Для отрицательных сырых состояний reflection задаёт private index, после
чего вызываются production методы. Отказ публичного `setIndex` записан отдельно.
Отображение может разрешить источник записи, для которой фабрика не создаёт
typed delegate; такие результаты имеют разные теги строк.

Приём физических int в Java не расширяет точный C++ профиль type8. Отказы фабрики
полей сохранены как наблюдения, а не как выдуманные отказы mapper.
См. [контракт](../../../spec/events/ORDER-INDEX.ru.md).
