# Оракул маршрутов Candle

[English version](README.md).

`CandleRoutesOracle` запускает Java-делегаты закреплённой версии QD из
[upstream.lock](../../../upstream.lock) для пяти физических каталогов.
Он записывает прямое и обратное преобразование символов, поля схемы и отказы.

Соберите исходник через JDK 8 с модулями из
[инструкции к оракулу Series](../series-oracle/README.ru.md). Запустите
`qdcxx.oracle.CandleRoutesOracle <новый-каталог>` в UTC и Pacific/Honolulu.
Офлайн-запуск создаёт каталог и записывает `routes.tsv`. Сравните файлы
побайтно. Без аргументов, с `--help` или `--help=ru` выводится справка.
Успех возвращает код 0. Неверные параметры или ошибка захвата дают ненулевой
код и могут оставить неполный вывод.
