# Форматирование C++

[English version](CPP.md). Английский документ является основным.

[Контракт стиля](../../docs/CPP-STYLE.ru.md) применяется к C++-компоненту QDCXX-010.
[Format-Cpp.ps1](Format-Cpp.ps1) запускает **Uncrustify 0.83.0 → clang-format 20.1.8** с неизменными
корневыми конфигурациями. Требуются PowerShell 7.4+ и Git; загрузка не требует Python или pip.

```powershell
pwsh -NoProfile -File tools/format/Setup-Cpp.ps1
pwsh -NoProfile -File tools/format/Format-Cpp.ps1 -Mode Format
pwsh -NoProfile -File tools/format/Format-Cpp.ps1 -Mode Check
```

[Setup-Cpp.ps1](Setup-Cpp.ps1) загружает точные Windows x64 archives из
[cpp-tools.lock.json](cpp-tools.lock.json), проверяет SHA-256 до распаковки и хранит всё в
игнорируемом `.work/`. Архив и хеш Uncrustify получены из официального GitHub release 0.83.0;
wheel и хеш clang-format — из метаданных PyPI release clang-format 20.1.8 (упаковка форматтера
в Python wheel, не runtime-зависимость). Кешированные архивы тоже проверяются.
Глобальная установка не выполняется. Повторный setup восстанавливает executables из проверенных архивов.

Setup использует только lock репозитория и `tools/format/.work/`; параметра для другого lock нет.
Загрузка идёт во временные файлы, которые проверяются до помещения в кеш архивов. Каждый архив,
включая попадание в прогретый кеш, проверяется по хешу до распаковки в новый промежуточный каталог.
Все имена и атрибуты ZIP проверяются до распаковки: абсолютные пути, выход через родительский каталог
с обоими разделителями, альтернативные потоки данных, имена устройств/неоднозначные имена Windows,
повторяющиеся пути и записи ссылок/специальных файлов/reparse отклоняются. Существующие точки reparse
файловой системы также отклоняются. Установка публикуется только при наличии ожидаемого executable;
ошибка распаковки сохраняет прежнюю установку. После ошибок временные файлы загрузки и распаковки удаляются.

Отдельные [проверки setup](../../tests/conformance/python-migration/Test-SetupCpp.ps1) проверяют
опасные архивы без сети через закрытый вспомогательный метод, реальную загрузку Windows с пустым/прогретым
кешем и существующий wrapper: отклонение неверных версий, Check без записи, Format и идемпотентность.
Для пустого кеша нужен доступ к сети; рабочие файлы сохраняются в `.work/python-migration-u3/`.
Этот путь загрузки предназначен только для Windows x64. В Linux/WSL можно использовать проверенное
форматирование на Windows-хосте или передать wrapper точные закреплённые версии нативных форматтеров;
эти Windows-архивы не содержат нативных инструментов Linux. [setup_cpp.py](setup_cpp.py) сохранён без
изменений для исторического воспроизведения и больше не является активной командой setup.

Wrapper проверяет версии обоих executables и отклоняет отсутствующие инструменты/конфигурации,
диагностику Uncrustify и предупреждения/ошибки clang-format. Необязательные пути `-Uncrustify` и
`-ClangFormat` также должны указывать на точные версии. Загрузка никогда молча не подменяет версии.
`Check` запускает оба инструмента на временных копиях, сравнивает байты и не переписывает оригиналы.
`Format` копирует результат pipeline обратно только при изменениях. Временные копии затем удаляются.

По умолчанию Git находит отслеживаемые и новые неигнорируемые файлы в `include/` (`*.hpp`), `src/`
(`*.cpp`) и `tests/conformance/` (`*.cpp`). Fixtures, upstream и generated-каталоги исключены.
`-Files` выбирает файлы в этих корнях либо `.work/` для намеренных негативных проверок;
остальные пути/расширения отклоняются. Новые расширения исходников добавляются явно при необходимости.
Имена, скобки, самодостаточность заголовка, комментарии пространств имён и содержательный Doxygen
проверены отдельно; форматтеры не обеспечивают все эти правила. Идемпотентность полного pipeline
и обнаружение расхождений без записи зафиксированы в
[валидации](../../tests/conformance/encoding/VALIDATION.ru.md).
Правила Java-форматирования и oracle provenance в [README](README.ru.md) остаются отдельными и неизменными.

QDCXX-017 расширяет поиск и проверку явно заданных файлов на `tools/qtp-inspect/*.cpp` и
`*.hpp`. Необязательный инструмент проходит тот же закреплённый двухэтапный pipeline; upstream,
fixtures и сгенерированные исходники не входят в область форматирования.

QDCXX-021 дополнительно включает tools/tape-inspect/*.cpp и *.hpp в тот же закреплённый набор
Format/Check. Прежние методы инспектора не меняются; tape-представление использует ограниченные helpers строк.
