# Декодер Kraken ticker

Необязательный компонент `qdcxx_kraken_decoder` декодирует ограниченные JSON-сообщения Kraken Spot WebSocket v2 ticker для профиля первого шлюза. Вызывающий код управляет соединением, проверяет запросы подписки и передаёт одно полное текстовое сообщение.

Декодер возвращает подтверждение подписки, heartbeat, состояние системы, снимок и обновление. Сообщение данных содержит одну или несколько записей BTC/USD. Цены и размеры преобразуются из десятичных токенов JSON непосредственно в QD wide decimal. Непредставимые точно значения отклоняются. Время провайдера сохраняется текстом. Времена Quote, sequence и коды биржи равны нулю.

Для сборки внутреннего компонента задайте `ORG_TTLDTOR_QDCXX_BUILD_KRAKEN_DECODER=ON`. При `BUILD_TESTING=ON` доступен его тест. По умолчанию компонент выключен. Подтверждение может содержать ID запроса, отказ содержит текст ошибки. Сообщение состояния содержит состояние системы провайдера.

Максимальный размер входа — 64 КиБ, число записей — 64, число полей каждого проверяемого объекта — 128, глубина вложенности — 32. Отсутствующие поля, неожиданные символы, повторные поля, некорректный JSON и непредставимые числовые значения приводят к ошибке. Сообщение возвращается только после проверки всех записей. Результат владеет своими данными. Компонент не открывает сокеты.

## Шлюз котировок Kraken

`qdcxx-kraken-gateway` передаёт публичный BBO BTC/USD в TICKER Quote на
`127.0.0.1`. Включите профили шлюза, источника Kraken и Feed с обычным
TCP. Для этого исполняемого файла отключите профиль QTP TLS. Источник
использует квалифицированный профиль Beast/OpenSSL и локальный PEM-файл
с доверенными сертификатами УЦ. Учётная запись не нужна.

```sh
qdcxx-kraken-gateway --help-ru
qdcxx-kraken-gateway --trust-pem /path/to/ca.pem --duration-ms 30000 --trace-quotes
```

Шлюз выводит `LISTEN 127.0.0.1 PORT`. Подключите клиентов QTP по указанному
порту и подпишитесь на композитный Quote с точным символом `BTC/USD`.
Значение `--listen-port` по умолчанию равно 0, порт выберет ОС. Источник
запускается при первом наблюдаемом запросе подписчика. Параметры
`--source-host`, `--source-identity` и `--source-port` задают маршрут и
проверяемое TLS-имя отдельно. Для живого подключения по умолчанию
используются `ws.kraken.com`, `ws.kraken.com` и `443`.
Укажите обычный локальный PEM-файл размером до 512 КиБ.

Шлюз передаёт новейшую котировку, доступную за проход цикла. Пока источник
активен, шлюз хранит одну котировку текущего поколения и повторно передаёт её
при наблюдаемом появлении спроса после паузы. При разрыве источника шлюз
сбрасывает эту копию. Если спрос клиентов сохраняется, коллектор TICKER
может передать новому подписчику последнее ранее принятое значение.
Первый новый снимок его заменяет. Шлюз больше не передаёт сброшенную копию.
TICKER может схлопывать ожидающие обновления. Доставка клиентам независима.

С ключом `--trace-quotes` после успешного приёма Publisher шлюз выводит строку.
Вывод синхронный и требует читающей стороны:

```text
PUBLISH GENERATION TIMESTAMP BID_RAW ASK_RAW BID_SIZE_RAW ASK_SIZE_RAW
```

Четыре поля RAW — знаковые слова QD wide decimal. Время поставщика
выводится как текст из символов представления RFC 3339. Если такой текст
нельзя поместить в строку трассировки, выходит `-`. Времена Quote равны
нулю. Счётчик `sent_frames` описывает запись в сокет. Для проверки
получения сравните котировки, принятые самими клиентами.

`--duration-ms` задаёт время приёма от запуска слушателя, от 1 до 600000 мс,
по умолчанию 30000 мс. Сначала завершается работа источника, затем закрывается
слушатель QTP. Завершение источника может ждать уже вызванный системный DNS.
Ctrl+C запрашивает остановку. Итоговая строка
`STATS observed=N published=N sent_frames=N retired_peers=N pending_publications=N`.
Код 0 требует хотя бы одну принятую публикацию, 1 означает ошибку или
отсутствие публикаций, 2 ошибку аргументов, 130 остановку сигналом.
