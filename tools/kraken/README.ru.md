# Декодер Kraken ticker

Необязательный компонент `qdcxx_kraken_decoder` декодирует ограниченные JSON-сообщения Kraken Spot WebSocket v2 ticker для профиля первого шлюза. Вызывающий код управляет соединением, проверяет запросы подписки и передаёт одно полное текстовое сообщение.

Декодер возвращает подтверждение подписки, heartbeat, состояние системы, снимок и обновление. Сообщение данных содержит одну или несколько записей BTC/USD. Цены и размеры преобразуются из десятичных токенов JSON непосредственно в QD wide decimal. Непредставимые точно значения отклоняются. Время провайдера сохраняется текстом. Времена Quote, sequence и коды биржи равны нулю.

Для сборки внутреннего компонента задайте `ORG_TTLDTOR_QDCXX_BUILD_KRAKEN_DECODER=ON`. При `BUILD_TESTING=ON` доступен его тест. По умолчанию компонент выключен. Подтверждение может содержать ID запроса, отказ содержит текст ошибки. Сообщение состояния содержит состояние системы провайдера.

Максимальный размер входа — 64 КиБ, число записей — 64, число полей каждого проверяемого объекта — 128, глубина вложенности — 32. Отсутствующие поля, неожиданные символы, повторные поля, некорректный JSON и непредставимые числовые значения приводят к ошибке. Сообщение возвращается только после проверки всех записей. Результат владеет своими данными. Компонент не открывает сокеты.
