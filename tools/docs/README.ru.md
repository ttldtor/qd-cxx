# Сборка документации

[English version](README.md) · [Документация разработчика](../../docs/developer.ru.md)

Публичный сборщик создаёт HTML-сайт с пользовательским входом, руководствами EN/RU, API C++ и отдельным
разделом разработчика. Нужны CMake 3.25+ и Doxygen 1.18+; Python, веб-фреймворк, компилятор и сеть
не требуются. Глобальные настройки не меняются.

Из корня репозитория:

```text
cmake -DHELP=ON -P tools/docs/Build.cmake
cmake -DDOXYGEN=/absolute/path/to/doxygen -DOUTPUT=/absolute/path/to/new-docs -P tools/docs/Build.cmake
```

В Windows заключайте весь аргумент в кавычки, если путь содержит пробелы, например
`"-DDOXYGEN=C:/Program Files/doxygen/bin/doxygen.exe"`. Откройте `OUTPUT/html/index.html` в браузере.
[Главная страница](../../docs/index.ru.md) задаёт тот же вход в исходном Markdown. Переключатель темы
меняет светлое и тёмное оформление. Выбор нового `OUTPUT` сохраняет прежний каталог документации.

GitHub Actions собирает тот же HTML для pull request в `master`. На Windows проверяются ядро и
офлайн-утилиты. На Linux проверяются Feed и офлайн-утилиты с ASan/UBSan. После успешных проверок
и сборки справки в `master` Actions публикует HTML на
[GitHub Pages](https://ttldtor.github.io/qd-cxx/).
Известные падения контрактных тестов перечислены в workflow и выводятся отдельным шагом.
Этот диагностический шаг не блокирует сборку и публикацию.

## Параметры и результат

| Параметр | По умолчанию | Значение |
| --- | --- | --- |
| `HELP=ON` | OFF | Справка и выход до проверок путей, поиска программ, работы с файлами и процессами |
| `SOURCE` | Текущий checkout | Явный корень исходников с `docs/index.md` |
| `OUTPUT` | `SOURCE/.work/docs` | Пустой каталог или каталог с меткой этого сборщика для тех же исходников |
| `DOXYGEN` | Поиск `doxygen` в PATH | Нативный генератор |

Код 0 означает успешную генерацию или справку. Код 1 — неверную конфигурацию, запрещённую ссылку,
ошибку подготовки или генератора; ошибки запуска CMake сохраняют его штатный код. Результат содержит
HTML/XML, `warnings.log`, сгенерированный `Doxyfile`, `sources.tsv`, `assets.tsv` и подготовленные
публичные входы. Собственные сгенерированные файлы могут перезаписываться; каталоги не удаляются.
Для отсутствия устаревших файлов предыдущей генерации выбирайте новый выходной каталог.

## Маршруты чтения и исходные файлы

Стандартный [layout Doxygen](layout.xml) определяет основную навигацию. Подготавливаются только страницы,
достижимые по явным локальным Markdown-ссылкам из двух главных страниц документации, публичные заголовки qd
и указанные обычные файлы. Отчёты conformance доступны из раздела разработчика, без алфавитного каталога
отчётов на пользовательском входе.

При сведении Markdown в плоские HTML-страницы Doxygen не меняет относительные ссылки на обычные файлы.
Сборщик направляет их в `html/assets`, сохраняя путь файла относительно репозитория. Поддержаны локальные inline-ссылки, определения ссылок на Markdown/заголовки, код в одиночных обратных кавычках и fenced code.
Определения ссылок на обычные файлы, локальные изображения и вложенные подписи raw-ссылок отклоняются явно; используйте inline-ссылку на файл. Код внутри блоков
сохраняется. Неподдержанный локальный синтаксис и отсутствующие файлы дают явную ошибку. Фрагменты
обычных файлов вроде `#L20` сохраняются как подсказки исходника; они не считаются проверенными HTML-якорями строк.

Пределы по умолчанию: `MAX_PAGES=1024`, `MAX_ASSETS=4096`, `MAX_FILE_BYTES=8388608` (8 MiB),
`MAX_ASSET_BYTES=67108864` и `MAX_SOURCE_BYTES=67108864` (по 64 MiB). Переопределение — `-DNAME=value`,
целое число в 1..2147483647. Общие пределы отдельно считают байты обычных файлов и входных Markdown/заголовков;
сгенерированные HTML/XML могут быть больше. Рабочие каталоги,
выход за корень, symlink/reparse-переходы и частные ключи запрещены. Исключение для ключей — ровно два
явно публичных тестовых server key TLS. Ссылки на каталоги ограничены конечными каталогами эталонов и журналов из `AssetDirectories.cmake`; остальные ссылки должны указывать файл.

Запустите [отдельные проверки сборщика](Tests.cmake) командой из этого файла. Предупреждения генератора
и проверка локальных ссылок решают разные задачи: нулевой код генератора сам по себе не доказывает
работу всех ссылок и примеров. Спецификации и conformance-данные остаются под Git по прежним путям.

## Известная особенность генератора

Doxygen 1.18.0 сохраняет в общем поиске дополнительную пустую запись файла `docs/index.md`.
Ссылки «Главная» ведут на настоящую главную страницу документации. Дополнительная запись поиска
остаётся известным ограничением генератора.
