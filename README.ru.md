# qd-cxx

Русский · [English](README.md)

`qd-cxx` — библиотека рыночных данных C++23 с сетевым получением и автономными утилитами анализа,
реализующая ограниченное подмножество
[devexperts/QD](https://github.com/devexperts/QD). Эталон совместимости — Java QD на ревизии из
[upstream.lock](upstream.lock). Поддержанные профили и пределы заданы явно; полная совместимость с QD не заявляется.

## Документация

1. [Начало работы](docs/getting-started.ru.md) — установить библиотеку и запустить небольшой потребитель.
2. [Практические руководства](docs/guides.ru.md) — tape, схемы, события и контролируемый STREAM.
3. [Справочник API](docs/api.ru.md) — публичные заголовки, цели линковки и контракты владения.
4. [Архитектура и протоколы](spec/README.ru.md) — ответственность компонентов и поведение на проводе.

Для типизированного сетевого приложения начните с [публичного feed API](docs/FEED-API.ru.md) и
[консольного примера Quote](examples/feed_quote/README.ru.md). Соединение и доставку обслуживает библиотека.

[Документация разработчика](docs/developer.ru.md) содержит параметры сборки, инструменты и результаты проверок.
[Соберите документацию](tools/docs/README.ru.md), чтобы пользоваться теми же маршрутами локально.

[Текст событий](docs/EVENT-TEXT.ru.md) выводит поддержанные события и значения с явным неизменяемым контекстом и готовой UTF-8 строкой.
