# Навигация по контрактам схем

[English version](README.md). Английская версия является нормативной.

## Нативный JSON: точка входа

[NATIVE-JSON](NATIVE-JSON.ru.md) определяет отдельный исходный формат `qdcxx-native` версии 1:
обычные записи, упорядоченные логические поля, точные полные типы 2/8/10/40/56/72/88/120 и явные
lookups. Необязательный загрузчик `qdcxx_schema_json` публикует владеющий неизменяемый `LocalSchema`
после ограниченной проверки. [Инструкции сборки/API](../../docs/CPP-BUILD.ru.md#нативный-загрузчик-json-схем)
показывают подготовку загруженных Quote/Profile по явным локальным ID;
[инспекция tape](../../docs/TAPE-INSPECT.ru.md) показывает общий вывод внешней схемы версии 6.
Пользовательские записи и дополнительные поля остаются доступными.

Повторно применимые нативные примеры: [пустая схема](examples/native/empty.json),
[типы полей](examples/native/field-types.json) и
[смешанные custom/Quote/Profile](examples/native/mixed.json).
Они описывают наш нативный синтаксис, а не новые наблюдения Java.
[XML-captured JSON-контракт](JSON-CONTRACT.ru.md), его примеры и исторические доказательства
остаются отдельными и неизменёнными; его профиль `qd-3.355-xml-captured` не поддерживается этим
загрузчиком. Построение из XML, imports, Java properties, новые типы/преобразования и транспорт
остаются вне нативной границы.
