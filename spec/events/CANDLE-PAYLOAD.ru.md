# Отображение полей Candle

[English version](CANDLE-PAYLOAD.md).

`qd/events/candle.hpp` предоставляет владеющие значения `Candle` и
`PreparedCandle`. Подключите `qdcxx_candle` в дереве исходников или из
установленного пакета. Mapper принимает явно выбранную
локальную запись и уже разрешённый `CandleSymbol`.

| Физическое отображение | Обязательные поля | Необязательные поля |
| --- | --- | --- |
| `CANDLE` | Time, Sequence, Open, High, Low, Close | Count, Volume, VWAP, Bid.Volume, Ask.Volume, ImpVolatility, OpenInterest |
| `TRADE_HISTORY` | Time, Sequence, Price, Size | Остальные физические поля проверяются как часть исходной записи |

TradeHistory задаёт Count равным единице, копирует Price во все четыре поля
OHLC и берёт Volume из Size. Отсутствующий Count в Candle даёт ноль.
Недоступные числовые значения дают NaN. Count использует целочисленное
преобразование исходного формата. Для wide-decimal точная половина округляется
к положительной бесконечности, а выход за диапазон насыщается на границе
знакового 64-битного числа. Остальные числовые getter-ы сохраняют прикладной
double Java. Целочисленные getter-ы объёма применяют сужение Java к этому double.

Индекс хранит знаковое слово секунд и все биты миллисекунд и sequence. Mapper
сохраняет флаги индексированного события и отдельное время FIELD. Результат
владеет данными. Перед отображением проверяются форма всех полей, происхождение
записи и лимит копирования символа.

[Java-оракул](../../tools/upstream/candle-payload-oracle/README.ru.md) сохраняет
результаты делегатов Candle, TradeHistory и фиксированного периода для wide- и
tiny-decimal, необязательных полей, LONG и границ удаления.
