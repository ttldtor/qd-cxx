# Физические маршруты Candle

[English version](CANDLE-ROUTES.md).

`PreparedCandleRoutes` принимает неизменяемую схему и явные ID записей одного
контракта доставки. При подготовке проверяются имена записей, отображение полей,
лимиты ресурсов и уникальность дескрипторов Java-делегатов.

| Имя записи | Выбор |
| --- | --- |
| `TradeHistory` | Тиковый период с полями TradeHistory |
| `Trade.<period>` | Фиксированный период с полями Candle |
| `Candle` | Общий резервный маршрут с полями Candle |
| `Candle{...}` | Фиксированный период или ценовая специализация одной минуты |

Для одной минуты сначала проверяется ценовая специализация, затем обычная
минутная запись, затем общая. Для других периодов приоритет у записи
фиксированного периода. Фиксированный атрибут задаёт сама запись, поэтому
он удаляется из физического символа. Биржа, сессия и остальные атрибуты
остаются в символе. `restore()` возвращает фиксированные атрибуты в
канонический владеющий CandleSymbol для полученного события.

Отсутствие маршрута, неверный дескриптор и превышение лимитов возвращают
структурированные ошибки до формирования физического запроса. Для HISTORY
вызывающая сторона передаёт индексированные записи.
[Java-оракул](../../tools/upstream/candle-routes-oracle/README.ru.md) проверяет
оба направления на TICKER и HISTORY.
