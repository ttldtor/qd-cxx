# Общие поля времени событий и региональные записи Quote

[English version](EVENT-TIME.md). Английская версия является основной.

Документ расширяет [подготовленные отображения](EVENT-MAPPING.ru.md) на основании закреплённых
production Java `MarketFactoryImpl`, `QuoteMapping`, `QuoteDelegate`, `ProfileMapping`,
`ProfileDelegate`, `MarketEventMapping`, `MarketEventDelegateImpl` и методов Quote.
Воспроизводимый [oracle](../../tools/upstream/event-time-oracle/README.ru.md) сохраняет
сгенерированные логические схемы, исходные значения cursor и результаты настоящих delegate
в `tests/fixtures/event-times/oracle.tsv`. Физические Java VOID tails исключены из логической
схемы без изменения значений long.

## Поля, единицы и отсутствие

| Свойство события | Точный локальный тип | Проекция и значение при отсутствии локального поля |
| --- | --- | --- |
| Quote `bidTimeMs`, `askTimeMs` | TIME_SECONDS (56), TIME_MILLIS (152) | Знаковые секунды ×1000 либо знаковые миллисекунды без изменения; при отсутствии0 |
| Quote `sequence` | SEQUENCE (72) | Младшие22 бита беззнакового исходного Sequence; при отсутствии0 |
| Quote `timeMs` | Необязательный SEQUENCE и время bid/ask | Округлить максимум времени вниз до целой секунды, прибавить беззнаковые биты31..22 Sequence (0..1023); без Sequence прибавить0 |
| Quote `timeNanoPart` | COMPACT_INT (8) | Исходное знаковое число наносекунд внутри миллисекунды; при отсутствии0; отображение сохраняет выходящие за диапазон значения, как Java |
| Коды exchange Quote | UTF_CHAR (2) | При наличии младшая UTF-16 единица, включая0; при отсутствии синтаксический exchange-суффикс записи либо0 для composite |
| Начало/конец halt Profile | TIME_SECONDS (56) | Знаковые секунды ×1000; при отсутствии0; эти сгенерированные поля не используют выбираемое TIME_MILLIS представление Quote |
| Quote/Profile `eventTime` | Явные метаданные вызывающей стороны | Миллисекунды от Unix epoch; по умолчанию0; независимо от business time, Sequence, индексной идентичности и происхождения маршрута |

Существующие обязательные поля цены/размера Quote и Description Profile, числовые значения
по умолчанию, точное сопоставление типов, владение строками и ошибки сохраняются. Присутствующий
неверный полный тип означает несовместимое отображение, а не отсутствие поля.
`dxscheme.bat=millis` задаёт создание Java-схемы; C++ получает проверенную схему и не читает
свойства процесса.

Quote `timeMs` повторяет Java long arithmetic, включая переполнение в дополнительном коде
на границах signed64. Для отрицательных миллисекунд применяется математическое округление
вниз, а не усечение к0. Десять старших битов Sequence сохраняются и при значениях больше999;
ни Sequence, ни TimeNanoPart не ограничиваются молча. Прежний восьмиполевой `mapQuote`
не меняется. У Profile нет business-свойств Sequence/nanosecond Quote; дополнительные поля
остаются generic.

На границе приёма `FIELD_METADATA` выбирает исходные FIELD-метаданные, когда они присутствуют.
Необязательный результат метаданных отличает отсутствие от времени0; прежнее числовое поле
события при неопределённом времени равно0. `UNSPECIFIED` не создаёт метаданные из business-полей
или индексного времени записи. Доставленное событие владеет символом и строками независимо
от схемы, decoder frame, callback и поколения reconnect.

## Региональная привязка и конечная область

`PreparedQuote` получает exchange из выбранного локального имени записи по синтаксическому
правилу `MarketEventSymbols.getExchangeCode`. Он восстанавливает этот суффикс в собственном
символе события, сохраняя завершающий блок атрибутов. Присутствующие exchange-поля имеют
приоритет перед значением записи. Exchange не связан с Order `#source` или происхождением маршрута.

Явно настроенный `EventRegistry::create` может содержать composite Quote, региональные Quote
и Profile в существующих пределах приёма16 записей/128 полей. Встроенный registry сохраняет
исходное composite-подмножество Quote/Profile. Этот контракт не заявляет полный региональный
каталог или общую реализацию selectors.

Для каждого поддерживаемого вида событий логический символ с зарегистрированным совпадающим
exchange выбирает эту запись и удаляет суффикс из физического QD-символа. Если регионального
совпадения нет, используется composite-маршрут с точным исходным логическим символом, как
в fallback Java delegate set. Выбранная запись и физический символ участвуют в существующих
desired-state membership, remove, reconnect и фильтрации доставки. Например, при настроенном
`Quote&Q` подписка `AAPL&Q` отправляет `Quote&Q`/`AAPL`; принятый Quote владеет `AAPL&Q`.
Запись другого exchange не удовлетворяет этому физическому membership. Смешанные composite/
regional подписки сохраняют отдельные record identities. Это совместимость детерминированного
локального wire; демонстрация публичного сервиса является отдельным наблюдением.

Native high-level API требует точной представимости выбранного регионального маршрута.
Преобразования Java не всегда обратимы: `AAPL&N&Q` превращается в физический `AAPL&N`,
а восстанавливается как `AAPL&Q`; `AAPL{x=y}&Q` восстанавливается как `AAPL&Q{x=y}`.
При совпадающем региональном Quote-маршруте `addSymbols`/`setSymbols` синхронно отклоняют
эти написания с `ErrorCode::INVALID_ARGUMENT` на `subscription-symbol-representation`.
Отклоняется вся попытка изменения; прежние selectors и wire interests сохраняются.
Worker повторяет проверку до выделения физического текста и публикации requests. Это явные
отказы native-подмножества; преобразования Java с потерями отдельно сохранены в
`tests/fixtures/event-times/representability.tsv`. Composite fallback и Profile сохраняют
буквальные написания. Обычный `AAPL&Q{x=y}` и представимые буквальные атрибуты перед
дополнительным завершающим блоком допустимы.

## Границы доказательств

Oracle покрывает default, только Sequence, только nano, оба поля, выбираемые миллисекунды
business time, отсутствие необязательных полей, перестановку полей и отсутствие обязательных.
Используются настоящие сгенерированные Quote, Quote&Q, Quote&z и Profile и production delegate:
границы signed32/signed64, отрицательное время, границы исходных Sequence/nano и независимые
метаданные событий. UTC и Pacific/Honolulu должны давать одинаковые байты. Native conformance
сравнивает владеющие и заимствованные проекции с этими результатами и отдельно проверяет
несовместимые типы, provenance, точные пределы символов и настоящий wire-маршрут установленного Feed.

Дополнительные наблюдения production `MarketEventDelegateImpl` и `MarketEventDelegateSet` покрывают
`AAPL&N`, `AAPL{x=y}`, `AAPL&N{x=y}`. Региональное преобразование заменяет существующий суффикс
и сохраняет атрибуты; преобразование подписки удаляет только суффикс. Для этого нужен
`changeExchangeCode`, а не `getBaseSymbol`, который удаляет и атрибуты. Реальный поиск exchange
в delegate set выбирает совпадающий зарегистрированный exchange, а при его отсутствии —
composite-элемент; composite delegate оставляет `AAPL&Q` неизменным. Вызовы сохранены как
строки `route` и `selection` рядом с наблюдениями значений.
