# Подготовленное отображение события Quote

[English version](QUOTE.md). Английская версия нормативна.

Подготовленный API дополняет неизменённый [прежний контракт восьми полей](../protocol/DEFAULT-QUOTE.ru.md).
Он следует [Java-доказательствам конфигураций](../schema/CONFIGURED-EVENTS.ru.md) и общим
[правилам владения отображением, контекста и валидации](EVENT-MAPPING.ru.md). Загрузка источника,
wire-привязка и проекция события разделены. Одно имя записи не доказывает совместимость.

## Выбор полей

Подготовка ищет явные local/property-ключи без выведения псевдонимов. Оба ключа могут указывать
на одно поле; разные цели отклоняются как неоднозначные. Дополнительные поддержанные поля сохраняются.

| Local-ключ | Property-ключ | Точные полные типы | Обязателен |
| --- | --- | --- | --- |
| Bid.Time | BidTime | 56 | нет |
| Bid.Exchange | BidExchangeCode | 2 | нет |
| Bid.Price | BidPrice | 120 или 8 | да |
| Bid.Size | BidSize | 120 или 8 | да |
| Ask.Time | AskTime | 56 | нет |
| Ask.Exchange | AskExchangeCode | 2 | нет |
| Ask.Price | AskPrice | 120 или 8 | да |
| Ask.Size | AskSize | 120 или 8 | да |
| Sequence | Sequence | 72 | нет |
| TimeNanoPart | TimeNanoPart | 8 | нет |

Числовые альтернативы измерены production-сценарием numeric-int. Они не разрешают wire-конверсию
или другие представления. Отсутствующее обязательное локальное поле отклоняет подготовку.
Отсутствующее необязательное локальное поле проецируется в ноль. Локальное поле, пропущенное на wire,
сохраняет типизированный raw-ноль декодера: числовой full120 означает NaN, а full8 означает ноль.

## Владеющие значения и время события

Результат владеет точным UTF-16 символом. Числовые full120 сохраняют исходные биты WideDecimal.
Числовые full8 становятся точным decimal события с коэффициентом, равным знаковому int32, и рангом
128 (raw = value * 256 + 128). Полученное представление события не меняет full8-тег и raw исходной
обобщённой записи; это не общий API создания decimal.
Знаковые секунды bid/ask умножаются на 1000 в int64. Exchange-коды сохраняют младшую UTF-16 единицу.

Sequence — упакованное signed32: старшие десять беззнаковых битов задают компоненту миллисекунд,
младшие 22 бита — публичный sequence. Поэтому timeMs равен max(bidTimeMs, askTimeMs) плюс старшая
беззнаковая компонента; отрицательные упакованные значения имеют смысл. TimeNanoPart сохраняет
знаковый raw int32, включая непосредственно измеренные границы вне обычных прикладных диапазонов.
EventTime — независимые metadata: вызывающий код может явно передать их в map, иначе это ноль.
Значение никогда не выводится из Sequence, TimeNanoPart или полей bid/ask.

## Бюджеты и совместимость

`PreparedQuote::prepare(schema, localId, limits)` возвращает неизменяемый план или MappingError.
`context()` предоставляет владеющий контекст записи. `map(symbol, values, symbolUnits, eventTime=0)`
принимает RecordValueView и возвращает владеющий Quote или MappingError, не сохраняя входное представление.

Подготовка владеет планом полей и контекстом в конечных MappingLimits. Проекция проверяет контекст
полной записи, все теги и каноничность payload до чтения выбранных значений и копирования символа.
Обязательный бюджет единиц символа проверяется до выделения памяти. Исключения выделения/длины
дают ALLOCATION_FAILURE; частичное событие не выходит. Код, сохраняющий несколько событий,
должен ограничивать совокупные сохраняемые единицы и работу.

Перестановка, явные псевдонимы, дополнительные поддержанные поля, отсутствие необязательных полей
и ненулевые локальные ID используют один подготовленный путь. defaultQuoteSchema, прежний mapQuote,
старые профили и байты вывода неизменны. Загрузчик, новый полный тип, regional/indexed события,
wire-конверсии и расширенная поддержка контейнеров не добавляются.
