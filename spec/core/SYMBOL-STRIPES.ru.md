# Разбиение символов на полосы

[English version](SYMBOL-STRIPES.md). Английская версия нормативна.

`qd/core/symbol_striper.hpp` предоставляет неизменяемые владеющие разбиения `SymbolStriper`
и листья `SymbolStripeFilter`. Эти значения классифицируют уже разрешённые физические UTF-16
символы. Полоса независима от канала QTP, источника события, эпохи подключения и домена
исполнения. Построение и запросы не запускают сеть, callbacks и не читают внешние настройки.

## Грамматика и выбор полосы

`SymbolStriper::parse` принимает пустую спецификацию или `by1` для MONO, `byhashN` для HASH
и `byrange-boundary-boundary-` для RANGE. Регистр значим, пробелы не игнорируются.
Количество хеш-полос записывается десятичными цифрами без знака в положительном диапазоне
Java int, является степенью двойки и не меньше двух. Начальные нули допустимы; имя использует
каноническую десятичную запись. Поэтому `byhash0004` превращается в `byhash4`, а строка
`byhash1` недопустима. Отдельная Java-фабрика по целому числу преобразует один в MONO;
такого перегруженного конструктора в native API нет.

Границы диапазонов непусты, строго возрастают и состоят из одной–восьми ASCII-букв или
цифр. Имя сохраняет допустимую запись диапазонов. Полос на одну больше, чем границ;
нижняя граница включается, верхняя исключается. MONO возвращает полосу ноль.

HASH вычисляет Java string hash по точным UTF-16 units, включая пустой текст, NUL,
непарные суррогаты и обе units дополнительного Unicode-символа. Умножение на 31, затем
на `0xB46394CD` выполняется по модулю 2^32. Полосу выбирают старшие log2(N) битов.
Нормализация Unicode, изменение регистра и проекция символа события не выполняются.

RANGE пропускает необязательный начальный множитель спреда `=[+-]?[0-9]+(\.[0-9]*)?*`,
затем префикс до первой ASCII-буквы или цифры. Используется не больше максимальной длины
границы, до восьми units; каждая кодируемая unit ограничивается значением `0x7F`,
64-битный ключ заполняется от старших байтов и дополняется нулями. Выбранный индекс равен
числу кодов границ, не превышающих ключ. Пустой значимый суффикс относится к первой полосе.
API соответствует строковому пути Java; нового API для сырой пары cipher/string или
смещения в массиве символов нет.

Каждая точная строка выбирает одну полосу. Явный ALL в подписке обрабатывается отдельно:
он должен попасть во все включённые полосы. Текстовый `*` не является инструкцией создания
ALL в этом API. Java wildcard cipher принимается всеми листьями полос; вызывающая сторона
передаёт такое условие явно через аргумент `wildcard`.

## Статические листья и пересечения

`stripeFilter(index)` создаёт независимо владеющий лист. MONO возвращает `*`, HASH —
`hashMofN`, где M дополнено слева нулями до десятичной ширины N, RANGE —
`range-left-right-` с пустыми открытыми концами. `SymbolStripeFilter::parse` принимает
эти статические формы; `range---` становится `*`. Произвольное полное выражение фильтра
возвращает `UNKNOWN_SPECIFICATION` и остаётся обязанностью верхней границы фильтрации.

Совместимые пары hash/hash и range/range дают доказанный непрерывный `StripeIntersection`
с включённым началом `first` и количеством `count`. MONO, ANY и разные виды возвращают
`nullopt`, как в production-оптимизации. Неизвестное пересечение требует рассматривать
все полосы; это никогда не доказанный пустой набор. При нераспознанном полном выражении
вызывающая сторона также сохраняет все полосы и продолжает применять настоящий предикат.

Эти листья не устанавливают фильтр подписки или событий. `FeedFilter` уже принимает
листья hash/range и синтаксис пересечения. Верхняя политика физических записей может
объединить своё прежнее выражение с сгенерированным листом; эта политика должна оставаться
действующей после выбора поднабора полос. Чистые core и collector targets не зависят
от API событий.

## Владение, ошибки и ограничения

Копии совместно владеют неизменяемым состоянием и допускают параллельные const-запросы.
Входные views заимствуются только на время вызова и не должны изменяться. Views имён
требуют живого владеющего значения или его копии. Значение по умолчанию и перемещённое
значение недействительны; простые наблюдения возвращают пустое имя/нулевое количество,
семантические запросы — `INVALID_STATE`.

`SymbolStriperLimits` передаётся обязательно и явно. Он ограничивает units входной
спецификации, число настроенных полос, units символа запроса и полные ёмкости сохраняемых
объектов, строк и векторов. Ноль означает ноль. Учёт backing консервативно включает
ёмкости строк вместе с объектным хранением; служебные данные allocator и RSS процесса
не входят в него. Генерируемый канонический лист ограничен сохраняемым backing, а не
пределом написания пользовательского входа. Метаданные HASH занимают постоянное место
даже при большом разрешённом количестве; создание реальных дочерних коллекторов требует
отдельного допуска и backing каждой полосы.

Некорректный известный синтаксис, неизвестный формат фабрики, неверный индекс, отказ
конечного ресурса и ошибка выделения памяти имеют разные отдельные ошибки. Построение
кандидата не публикует частичное значение. Выбор полосы, проверка листа и пересечения
не выделяют память. Ошибка или завершённая классификация не означают запись в wire,
доставку, завершение snapshot или повторное подключение.
