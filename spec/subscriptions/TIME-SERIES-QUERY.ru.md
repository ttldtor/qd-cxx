# Политика диапазона снимка временного ряда

Ограниченный запрос временного ряда использует включительные границы бизнес-времени в миллисекундах. Обратный диапазон отклоняется. Активный запрос диапазона, полностью лежащего вне представимых времён событий, завершается пустым результатом без эпохи источника. Пассивное чтение сообщает об отсутствии интереса либо возвращает незавершённое состояние: для пустого диапазона источник не выбирается. Диапазон кандидатов в сохранённой истории задаётся включительными знаковыми упакованными индексами времени и последовательности, а окончательный отбор проверяет бизнес-время каждого события по исходным границам до применения ограничения числа результатов.

Поле миллисекунд в упакованном индексе занимает десять бит. Значения 1000–1023 перекрывают первые 24 миллисекунды следующей секунды, поэтому минимальный единый диапазон raw-индексов может содержать лишние записи. Они расходуют ограниченный бюджет сканирования, но не лимит результатов. Включительная верхняя граница охватывает все последовательности запрошенной миллисекунды. Расчёт ограничивается представимым временем события без переполнения на границах signed 64-bit.

Возвращаются независимые владеющие события, упорядоченные по бизнес-времени и затем по raw-индексу при совпадении времени; флаги событий обнуляются. Превышение лимита результатов или независимого бюджета сканирования/сравнений даёт явную ошибку без частичного успешного результата. Состояние коллектора не меняется. `SNAPSHOT_SNIP` выше запрошенной нижней границы остаётся признаком усечённого результата; незавершённый или неподписанный диапазон не объявляется полным. Владение подпиской, асинхронное завершение, отмена и отдельный предел сканирования обеспечиваются интеграцией запроса снимка.

Java API документирует обе границы включительными. В закреплённой ревизии преобразование верхней границы обнуляет биты последовательности и может исключить ненулевую последовательность на самом `toTime`. Здесь соблюдается документированный контракт включительного бизнес-времени. Эвристика предварительной загрузки за предыдущий день не применяется.

Для временного селектора используется начало секунды нижнего raw-индекса, которое может быть до 1023 миллисекунд раньше запрошенной бизнес-границы. Уже действующая подписка с применённой raw-границей выше необходимой не подтверждает полный результат; обычные подписки с полным покрытием остаются пригодными.
