# Контракт значений glossary

[English](VALUES.md). Английский текст является нормативным.

Источник — production `dxfeed-api` классы `com.dxfeed.glossary.CFI` и
`AdditionalUnderlyings` в [закреплённой версии](../../upstream.lock). Формат карты использует
`dxlib` MathUtil/FastDoubleUtil precision 15. Значения входят в optional `qdcxx_ipf` без
обратной зависимости Feed и без неявной валидации полей профиля.

## CFI

Вход содержит до шести A–Z UTF-16 units; короткие коды дополняются X. Null, пустая строка
и integer zero дают XXXXXX. Упаковка — шесть пятибитных полей A=1…Z=26, первая буква старшая,
верхние два бита нулевые. Ошибки длины, верхних битов и символов вызывают `std::invalid_argument`
с точными сообщениями `code is too long`, `code is invalid`, `code contains invalid character`
в порядке проверок Java.

Категория/группа — первые две буквы; E/D/R/O/F/M predicates читают только категорию.
Неизвестная стандарту комбинация допустима. Сохранены все активные категории, группы,
порядок атрибутов/значений, имена и описания, включая draft structured/referential категории.
Закомментированный старый EU mapping исключён; активный шестой атрибут — Strategy.
Неопределённая группа/атрибут использует Undefined. Отсутствующий X в известном атрибуте
даёт Unknown, другая отсутствующая буква — Unrecognized с исходной буквой и атрибутом.
Undefined явно содержит X=Undefined. Описание соединяет шесть имён через `; `.
Дескрипторы и `Cfi::EMPTY` инициализируются константно, не требуют динамического словаря/кеша.

## Дополнительные базовые активы

Документированная грамматика: `TEXT := "" | AU ("; " AU)*`, `AU := SYMBOL " " SPC`.
Реализация Java дополнительно допускает начальный `;`, табуляции, NUL и непарные UTF-16 units
в символах, дубликаты и несортированный текст. ASCII space/semicolon в символе запрещены.
Разбор идёт справа налево, сохраняет исходный текст; для дубликата побеждает первое текстовое
вхождение. Ошибки разделителей дают `inappropriate use of separators`, SPC —
`SPC is missing or infinite`. Null/пустой текст даёт пустые текст/карту. C++ карта упорядочена
по UTF-16 units; порядок Java HashMap не является контрактом.

SPC: необязательный знак, цифры с не более чем одной точкой, хотя бы одна цифра, необязательная
E/e экспонента. После E/e нужен один символ, но знак без цифр принимается как нулевая экспонента.
Арифметика экспоненты и вычитание количества дробных цифр повторяют signed32 wrap; sentinel
2147483647 запрещён. Мантисса накапливается binary64 умножением на десять и сложением. Масштаб
использует правильно округлённые binary64 степени 10^0…10^308. Итоговая экспонента вне ±308 даёт
signed zero либо infinity до умножения/деления; внутри — обычное масштабирование. Пробельные
символы, NaN/Infinity, hex и суффиксы запрещены. Числовое переполнение до infinity допустимо,
NaN запрещён. Знак нуля сохраняется.

Метод экземпляра читает карту, отсутствующий символ даёт +0. Статический SPC lookup не проверяет
весь текст, ищет справа до первого не-NaN совпадения; поэтому при дубликатах берёт последнее
валидное вхождение. Null/пустые текст или символ дают +0.

Создание из карты сортирует символы; пустой ключ даёт `symbol is empty`, space/semicolon —
`symbol contains prohibited character`, неограниченное/NaN число — `SPC is missing or infinite`.
C++ ключи/значения не представляют Java null key/boxed SPC; null карта сама по себе пуста.
Формат сохраняет signed zero и округляет кратчайшие десятичные цифры upstream half-up по
величине до 15 значащих цифр. Кратчайшее преобразование исключает границы бинарного интервала
округления; включённая host-граница может создать ложную десятичную середину. Это отличается
от прямого округления точного binary64 до 15 цифр. Формат удаляет хвостовые
нули; для исходной величины [1e-9,1e10) пишет fixed, иначе scientific с E без плюса.
Минимальные subnormal сохраняют дополнительную цифру production, включая 4.9E-324.
Результат снова разбирается; округление и legacy exponent window могут изменить SPC.
Политики IPF и Candle-period не меняются; shared decimal arithmetic используется узко для
subnormal digits.

## Владение, ошибки и пределы

Фабрики заимствуют входы только на время вызова и возвращают владеющие значения. Ссылки на
текст/карту живут до изменения/уничтожения владельца. Metadata views живут всё время программы,
возвращаемые контейнеры независимы. Copy assignment готовит полную замену до изменения объекта;
ошибка выделения сохраняет старое значение. Успешный move оставляет AU пустым и пригодным для повторного использования; ошибка выделения sentinel пустой карты до переноса сохраняет источник. Allocation failures распространяются; ошибочная фабрика не публикует частичный
результат. Независимые immutable значения допускают конкурентное чтение; изменение/уничтожение
требует синхронизации.

`AdditionalUnderlyingLimits`: по умолчанию 1 048 576 UTF-16 units и 16 384 entries, включая
дубликаты. Длина входа/выхода также ограничена signed32 индексацией Java. Превышение вызывает
`std::length_error`. Это логический размер модели, не точный RSS/stream budget. Статический lookup
не выделяет память, не хранит модель и не имеет скрытого progress budget. Обычный пример использует
значения по умолчанию.
