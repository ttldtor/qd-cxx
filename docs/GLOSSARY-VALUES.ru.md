# CFI и дополнительные базовые активы

[English](GLOSSARY-VALUES.md). Английский текст является нормативным.

Включите `ORG_TTLDTOR_QDCXX_BUILD_IPF=ON` и линкуйте `qdcxx_ipf`. Публичные заголовки
`qd/glossary/cfi.hpp` и `qd/glossary/additional_underlyings.hpp` самодостаточны.
Feed, runtime, сеть и TLS не нужны. При IPF OFF эти заголовки и target не устанавливаются.

```cpp
#include <qd/glossary/cfi.hpp>
#include <qd/glossary/additional_underlyings.hpp>

int main() {
    using namespace org::ttldtor::qdcxx::glossary;
    constexpr auto code = Cfi::valueOf(std::u16string_view(u"OP"));
    static_assert(code.isOption() && code.getGroup() == 'P');
    const auto underlyings = AdditionalUnderlyings::valueOf(std::u16string_view(u"AAPL 2; USD 10"));
    return code.getCode() == "OPXXXX" && underlyings.getSpc(std::u16string_view(u"AAPL")) == 2 ? 0 : 1;
}
```

`Cfi` принимает от нуля до шести заглавных ASCII-букв, дополняет код X и трактует null,
пустую строку и упакованный integer zero как XXXXXX. Некорректные символы/поля вызывают
`std::invalid_argument`; неизвестные стандарту комбинации допустимы. `decipher()` возвращает
шесть небольших значений со ссылками на неизменяемый словарь, живущий всё время программы.
Имена и описания переживают Cfi и результат расшифровки. `getValues()` копирует только список
небольших значений; `describe()` соединяет шесть имён. Создание Cfi и запросы категории доступны
при constant evaluation; `Cfi::EMPTY` инициализируется константно, в том числе для доступа
из другой единицы трансляции до main.

`AdditionalUnderlyings` владеет точной UTF-16 строкой и картой символ/SPC. Разбор сохраняет
порядок/написание текста; при дубликатах побеждает первое вхождение. Равенство сравнивает текст.
Создание из карты сортирует UTF-16 символы, округляет кратчайшие цифры открытого интервала upstream до 15 значащих цифр и разбирает результат:
карта хранит уже округлённые значения. Текст может дать infinity через переполнение экспоненты;
карта запрещает неограниченные/NaN SPC. Знак нуля сохраняется, локаль не влияет на результат.
Null строка/карта даёт пустое значение. `empty()` безопасно создаётся при первом обращении.

Метод экземпляра `getSpc(symbol)` читает разобранную карту. Статический `getSpc(text, symbol)`
намеренно ищет справа без проверки всего текста, поэтому для дубликатов и некорректных строк
результат может отличаться. Null/пустой символ статического запроса даёт ноль. Это совместимость
с upstream, а не универсальный числовой парсер.

По умолчанию действуют конечные пределы 1 048 576 UTF-16 units и 16 384 разобранных entries,
включая дубликаты. `AdditionalUnderlyingLimits` позволяет выбрать иные конечные пределы при
создании. Превышение даёт `std::length_error`; синтаксис — `std::invalid_argument` с production
сообщением. Ошибки выделения памяти распространяются. Входные views не сохраняются. Copy
assignment сначала готовит полное значение; ошибка выделения сохраняет целевой объект. Успешный move оставляет источник пустым и пригодным к повторному использованию; ошибка выделения sentinel пустой карты до переноса сохраняет источник. Ссылки на текст/карту действуют
до изменения/уничтожения владельца. Независимые неизменяемые значения допускают конкурентное
чтение; изменение и уничтожение требуют синхронизации с читателями.
