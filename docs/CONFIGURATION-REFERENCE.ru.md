# Справочник конфигурации

[English](CONFIGURATION-REFERENCE.md) · [Архитектура конфигурации](CONFIGURATION.ru.md)

Записи по декларациям сохраняют известные сведения деклараций и исходников, включая ограничения, момент чтения и время жизни, с оговоркой об отсутствии независимой перепроверки. Незавершённая семантическая проверка не отменяет эти сведения; НЕИЗВЕСТНО используется только для действительных пробелов.

Выберите подсистему, затем найдите поле C++: для него указаны исходное значение, единицы, проверка, момент чтения, изменяемость и ошибки. Имена владельцев повторяются в разных пространствах имён; нужный тип определяет ссылка на исходник. Постоянные идентификаторы CFG обозначают строки справочника, а не поддержанные Java properties.

Охват: 937 деклараций из 67 исходников публичных заголовков, утилит и примера. Для 585 полей описана семантика потребителя; ещё 352 строки отдельно классифицированы по декларациям. Вторая группа включает 107 составных входов, 86 входных рабочих кредитов, 103 конечных параметра, 8 явных зависимостей/данных, 13 констант, 31 возвращаемое наблюдение и 4 описания условий проверки. НЕИЗВЕСТНО обозначает пробел в сведениях, а не проверку, поддержку или обещание изменения во время работы. Константы, наблюдения и описания условий проверки не являются пользовательскими настройками.

Границы — каталог объявленных нативных настроек. Он не перечисляет все переключатели CMake, написания CLI-параметров или Java QD properties. [Справочник свойств endpoint](ENDPOINT-CONFIGURATION.ru.md) описывает поддержанные текстовые имена и приоритеты; [базовая проверка настроек схем](../spec/schema/CONFIGURED-EVENTS.ru.md) — наблюдённые Java-приоритеты. Остальные семейства Java-настроек остаются нереализованными или неразрешёнными, если документация компонента не устанавливает иное. Совпадение декларации со справочником не доказывает поведение при исполнении; исходный контракт и фактический запуск — разные доказательства.

Отсутствие инициализатора указано явно; это не означает, что неопределённое значение допустимо читать. Ноль, отсутствие и пустое значение сохраняют смысл своего компонента. Исходные значения взяты из деклараций и не являются рекомендациями по производительности или пределами протокола. Рабочие кредиты, удерживаемая ёмкость и возвращаемые оценки требуемых ресурсов остаются разными сущностями.
