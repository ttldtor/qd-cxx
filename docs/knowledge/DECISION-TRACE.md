## Reading a missing link

A source fact without a production observation remains source evidence. A Java observation without a
native comparison remains compatibility input. A selected ADR without an implemented contract remains
a design decision. For a new channel or route proposal, identify the missing observable requirement
before extending a protocol, storage model or public API. Concrete deployment design remains outside
this knowledge base.
