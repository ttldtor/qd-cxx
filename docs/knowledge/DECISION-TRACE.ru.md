# Связи требований и решений

[English version](DECISION-TRACE.md). Английская версия является нормативной. [Указатель](README.ru.md).

Таблица связывает [реестр требований](REQUIREMENTS.ru.md), наблюдаемые контракты и доказательства.
«QD pin» означает 3.355 / `0ddc0a09779fb61d74cc0b37c6449ff47dcb715f` из
[upstream.lock](../../upstream.lock). Нативный статус относится к базе редакции из указателя.
Связанные отчёты сохраняют свои платформы, режимы сборки, версии и исключения; таблица не запускает
и не расширяет их проверки. Предлагаемые ниже проверки — недостающие доказательства, а не успешные
тесты или новые принятые требования.

## Как читать отсутствующую связь

Факт из исходников без production-наблюдения остаётся доказательством уровня исходников.
Java-наблюдение без нативного сравнения остаётся входом для проверки совместимости. Выбранный ADR
без реализованного контракта остаётся проектным решением. Для нового предложения о канале или
маршруте нужно определить недостающее наблюдаемое требование до расширения протокола, модели хранения
или публичного API. Конкретная схема развёртывания находится вне базы знаний.
