### `ContainerLimits::compressedBytes` — CFG-0885 {#cfg-0885-ru}

- Тип: `std::uint64_t`. Исходное значение: `= 67108864`
- Источник: явный нативный вход указанного владельца; источник слоя свойств, где он поддержан, определяется resolver endpoint. Семантика отдельного поля установлена по потребителю.
- Единицы: физически прочитанные сжатые байты
- Допустимые значения: UINT64_MAX явно запрещён на первом read, чтобы оставить один диагностический выход за предел probe. 0 оставляет 0 обычных байтов, но одно контрольное чтение может установить физический EOF/превышение.
- Момент чтения: Конструктор CompressedInput копирует профиль без выделения памяти и ввода. Первое чтение проверяет представимость; дальнейшие чтения применяют счётчики при потреблении данных.
- Изменяемость и время жизни: Профиль постоянен у декодера; уничтожение не читает и не закрывает заимствованный поток.
- Ошибка: Исчерпание данной области — ContainerError::COMPRESSED_LIMIT; ошибка становится липкой, уже произведённая начальная часть остаётся в результате. Значение UINT64_MAX отдельно даёт INVALID_ARGUMENT на первом read.
