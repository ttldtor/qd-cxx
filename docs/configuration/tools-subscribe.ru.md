### `Configuration::host` — CFG-0839 {#cfg-0839-ru}

- Тип: `std::string`. Исходное значение: Инициализатора в классе нет. Это не доказывает обязательность ввода; инициализация значением отличается.
- Источник: явный нативный вход указанного владельца; источник слоя свойств, где он поддержан, определяется resolver endpoint. Семантика отдельного поля установлена по потребителю.
- Единицы: байты числового адреса
- Допустимые значения: Обязательный адрес IPv4/IPv6 длиной 1..45; inet_pton должен принять; URI, идентификатор зоны и DNS не поддержаны этой программой.
- Момент чтения: parseArguments проверяет и копирует адрес; effectiveEndpoint записывает configuration.host в settings.host перед EndpointOptions::create.
- Изменяемость и время жизни: Configuration — владеющий результат парсинга; действующий запуск не наблюдает позднее изменение внешнего объекта.
- Ошибка: Ошибка разбора этого поля возвращает строку "--host requires a numeric IPv4/IPv6 literal"; main прежнего режима завершает работу кодом 1. Если длина допустима, но inet_pton не принял адрес, строка — "--host requires a numeric IPv4/IPv6 literal without a zone". Отсутствующий host попадает в общую проверку обязательных --host/--port/--symbol. При отдельном вызове effectiveEndpoint недопустимый адрес даёт EndpointError::INVALID_CONFIGURATION, стадия=endpoint-address.
- Исходники потребителя: [src/client/endpoint_options.cpp](../../src/client/endpoint_options.cpp).
