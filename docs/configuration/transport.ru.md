## RecoveryBlueprintCapacity {#cfg-0687-owner-ru}

[include/qd/transport/recovery.hpp](../../include/qd/transport/recovery.hpp)

### `RecoveryBlueprintCapacity::records` — CFG-0687 {#cfg-0687-ru}

- Тип: `std::size_t`. Исходное значение: `= 0`
- Источник: явный нативный вход указанного владельца; источник слоя свойств, где он поддержан, определяется resolver endpoint. Семантика отдельного поля установлена по потребителю.
- Единицы: слоты OutgoingRecord свежей копии
- Допустимые значения: Для blueprintCopy.records измеренная потребность одной свежей копии ≤ предел; для adoptedBlueprint.records отдельно сравнивается фактическая вместимость переданного вектора/строк. 0 допускает только нулевую потребность.
- Момент чтения: inspectRecoveryCopies до создания SubscriptionWriter; этот же тип применяется к отдельным copied и переданный во владение координатам.
- Изменяемость и время жизни: Неизменяемо в RecoveryOptions; внешний план исходящих объявлений передаётся только при успешном завершении фабрики.
- Ошибка: Нехватка координаты — RecoveryError::RESOURCE_LIMIT, стадия=recovery-blueprint-capacity; переполнение — recovery-copy-arithmetic.
- Исходники потребителя: [include/qd/transport/recovery.hpp](../../include/qd/transport/recovery.hpp), [src/transport/recovery_copy_profile.cpp](../../src/transport/recovery_copy_profile.cpp).

- Источник: явный нативный вход указанного владельца; источник слоя свойств, где он поддержан, определяется resolver endpoint. Семантика отдельного поля установлена по потребителю.
- Единицы: байты полного консервативного бюджета TLS одного запуска
- Допустимые значения: residentBytes обязан быть &gt;0 и вмещать adapterBytes+snapshotBytes+settings.budgets.tcp.residentBytes+sdkInstanceBytes+sdkSharedBytes. Все суммы проверяются; 0 отдельно отвергается.
- Момент чтения: Проверяется на фабрике TLS до активации, после tlsRequirements и расчёта фактической вместимости снимка.
- Изменяемость и время жизни: Постоянно у владельца ресурсов TLS.
- Ошибка: 0 даёт TlsError::RESOURCE_LIMIT, tls-sdk-allowance. Переполнение построения adapterBytes/snapshotBytes даёт RESOURCE_LIMIT, tls-resident-arithmetic. Переполнение сложения в reservation.totalBytes и превышение options.residentBytes дают RESOURCE_LIMIT, tls-resident-allowance.
- Исходники потребителя: [include/qd/transport/tls_runtime.hpp](../../include/qd/transport/tls_runtime.hpp), [src/transport/tls_runtime.cpp](../../src/transport/tls_runtime.cpp).
