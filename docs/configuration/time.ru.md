Известные объявленные сведения сохраняются; их семантическая проверка ещё не завершена. Ссылки указывают декларацию или потребителя и не означают нового запуска тестов. ### `TimeZoneBindingOptions::rawOffsetReferenceTime` — CFG-0681 {#cfg-0681-ru}

- Тип: `std::optional<std::int64_t>`. Исходное значение: Инициализатора в классе нет. Это не доказывает обязательность ввода; инициализация значением отличается.
- Источник: явный нативный вход указанного владельца; источник слоя свойств, где он поддержан, определяется resolver endpoint. Семантика отдельного поля установлена по потребителю.
- Единицы: знаковые Unix-миллисекунды опорного времени
- Допустимые значения: nullopt один раз читает system_clock::now при создании привязки; явное значение int64_t сохраняется точно. При определении стандартного смещения переменной зоны время вне диапазона [-2208988800000, максимум provider] заменяется максимумом provider. Для фиксированных зон и прежних идентичностей результат не зависит от опорного времени.
- Момент чтения: ZoneBinding::create после проверки идентичности выбирает и сохраняет опорное время. Последующие запросы смещения не перечитывают часы конструктора.
- Изменяемость и время жизни: create один раз выбирает переданное время либо текущее время часов и сохраняет выбранное значение в модели. Изменение исходного options не меняет существующий binding.
- Ошибка: Само поле не отвергает int64_t. Ошибки вычисления смещения поставщиком данных отображаются в TimeZoneError; исходное опорное время остаётся в неизменяемой модели.
- Исходники потребителя: [include/qd/time/time_zone_data.hpp](../../include/qd/time/time_zone_data.hpp), [src/time/time_zone_data.cpp](../../src/time/time_zone_data.cpp).

### `TimeZoneBindingOptions::maxIdUnits` — CFG-0682 {#cfg-0682-ru}

- Тип: `std::size_t`. Исходное значение: `= 128`
- Источник: явный нативный вход указанного владельца; источник слоя свойств, где он поддержан, определяется resolver endpoint. Семантика отдельного поля установлена по потребителю.
- Единицы: кодовые единицы UTF-16 точного ID часового пояса
- Допустимые значения: Любое представимое значение maxIdUnits допускается как порог сравнения; отдельной проверки верхней границы порога нет. Требуется id.size()&lt;=maxIdUnits. При нуле пустой ID проходит длину, затем получает INVALID_ID. Грамматика смещения, известная идентичность и проверяемый размер собственной копии ID — отдельные проверки самого входа.
- Момент чтения: ZoneBinding::create проверяет длину до поиска идентичности и копирования в модель.
- Изменяемость и время жизни: Лимит применяется к одному вызову ZoneBinding::create и в результате не сохраняется. Следующий вызов может передать другой лимит независимо от существующих binding.
- Ошибка: TimeZoneError::RESOURCE_LIMIT при превышении/переполнении bindingLogicalBytes; INVALID_ID при неизвестной идентичности; ALLOCATION при bad_alloc.
- Исходники потребителя: [include/qd/time/time_zone_data.hpp](../../include/qd/time/time_zone_data.hpp), [src/time/time_zone_data.cpp](../../src/time/time_zone_data.cpp).

### `TimeZoneLimits::files` — CFG-0672 {#cfg-0672-ru}

- Тип: `std::size_t`. Исходное значение: `= 11`
- Источник: явный нативный вход указанного владельца; источник слоя свойств, где он поддержан, определяется resolver endpoint. Семантика отдельного поля установлена по потребителю.
- Единицы: файлы контролируемого набора
- Допустимые значения: files&gt;=APPROVED_FILE_COUNT=11. Читаются лишь 11 файлов утверждённого перечня; дополнительный допуск файлов не расширяет профиль. Ноль вызывает отказ до открытия данных.
- Момент чтения: TimeZoneData::initialize передаёт допуск в provider::initialize с состоянием на срок процесса. После начальной проверки формы входа первый EMPTY→INITIALIZING занимает единственную попытку. Затем выполняются проверки файлов и построение модели. Сборка без модуля возвращает NOT_READY до потребления лимитов.
- Изменяемость и время жизни: У этого поставщика инициализация допускается один раз на процесс. Успех оставляет READY, ошибка после принятия — FAILED; оба состояния не возвращаются в EMPTY. Новый объект фасада не сбрасывает состояние допуска. Для новой принятой попытки с другими лимитами нужен новый процесс поставщика.
- Ошибка: provider::Error::LIMIT отображается в TimeZoneError::RESOURCE_LIMIT; повторная попытка после принятой инициализации также RESOURCE_LIMIT. Аллокация→ALLOCATION; неправильные данные→DATA.
- Исходники потребителя: [include/qd/time/time_zone_data.hpp](../../include/qd/time/time_zone_data.hpp), [src/time/time_zone_data.cpp](../../src/time/time_zone_data.cpp), [src/time/timezone/provider.cpp](../../src/time/timezone/provider.cpp).

- Допустимые значения: admitNativeModel проверяет modelUnits&lt;modelLimit перед каждой вставкой, включая временные/позднее отброшенные модели. Ноль запрещает первую вставку. Счётчик не возвращает единицы бюджета при erase.
- Момент чтения: TimeZoneData::initialize передаёт допуск в provider::initialize с состоянием на срок процесса. После начальной проверки формы входа первый EMPTY→INITIALIZING занимает единственную попытку. Затем выполняются проверки файлов и построение модели. Сборка без модуля возвращает NOT_READY до потребления лимитов.
- Изменяемость и время жизни: У этого поставщика инициализация допускается один раз на процесс. Успех оставляет READY, ошибка после принятия — FAILED; оба состояния не возвращаются в EMPTY. Новый объект фасада не сбрасывает состояние допуска. Для новой принятой попытки с другими лимитами нужен новый процесс поставщика.
- Ошибка: provider::Error::LIMIT отображается в TimeZoneError::RESOURCE_LIMIT; повторная попытка после принятой инициализации также RESOURCE_LIMIT. Аллокация→ALLOCATION; неправильные данные→DATA.
