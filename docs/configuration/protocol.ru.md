### `DescriptionLimits::payloadBytes` — CFG-0519 {#cfg-0519-ru}

- Тип: `std::size_t`. Исходное значение: Инициализатора в классе нет. Это не доказывает обязательность ввода; инициализация значением отличается.
- Источник: явный нативный вход указанного владельца; источник слоя свойств, где он поддержан, определяется resolver endpoint. Семантика отдельного поля установлена по потребителю.
- Единицы: байты полного содержимого без оболочки кадра
- Допустимые значения: payload.size() ≤ payloadBytes. 0 допускает только пустой payload.
- Момент чтения: parseDescribeRecords, detail::parseSessionDescriptions и detail::parsePmrDescriptions передают копию DescriptionLimits в DescriptionReader; поле проверяется при соответствующем действии разбора содержимого.
- Изменяемость и время жизни: Отдельный вызов получает новый бюджет; результата парсинга эта настройка впоследствии не меняет.
- Ошибка: Нарушение указанной границы — DescriptionStatus::RESOURCE_LIMIT. Синтаксические ошибки строки/заголовка имеют свои статусы и не подменяются общей ошибкой настройки.
