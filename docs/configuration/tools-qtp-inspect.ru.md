# Просмотр QTP

[English](tools-qtp-inspect.md) · [Оглавление справочника](../CONFIGURATION-REFERENCE.ru.md)

Контракты потребителей отдельных полей и сведения деклараций/исходников с оговорённой доказательностью явно различаются ниже. НЕИЗВЕСТНО обозначает недостающее сведение. Известные объявленные сведения сохраняются; их семантическая проверка ещё не завершена. Ссылки указывают декларацию или потребителя и не означают нового запуска тестов. Значения описывают текущий API; принятые изменения перечислены в [архитектурном контракте](../CONFIGURATION.ru.md).

### `Limits::chunkSize` — CFG-0821 {#cfg-0821-ru}

- Тип: `std::size_t`. Исходное значение: `= 4096`
- Классификация: конечный параметр: ниже приведены сведения с оговорённой доказательностью. Контракт декларации или исходника, без независимой перепроверки. Семантическая проверка поля и его времени жизни ещё не завершена; запуск runtime-тестов не заявляется.
- Источник: указанная декларация. Явный типизированный вход; псевдоним свойства и отдельный приоритет поля не установлены.
- Объявленное назначение: Положительное число входных байтов одного чтения.
- Единицы: НЕИЗВЕСТНО: см. объявленное назначение; дополнительные единицы из типа не выводятся
- Объявленные ограничения: Положительное число входных байтов одного чтения.
- Момент чтения: Явный разбор и подготовка CLI до рабочего I/O, кроме отдельно обозначенных runtime-состояний и наблюдений.
- Изменяемость и время жизни: Общего CLI-пути обновления во время работы нет; только явные операции конкретной команды.
- Ошибка: Ошибка использования CLI или ограниченной рабочей операции; см. parser и справку соответствующей команды.
- Дополнительный перечень ошибок/статусов владельца (без соответствия полю): `CLI ArgumentStatus/static rejection or owning typed result; contract excerpts below`.

### `Limits::input` — CFG-0822 {#cfg-0822-ru}

- Тип: `std::size_t`. Исходное значение: `= 67108864`
- Источник: явный нативный вход указанного владельца; источник слоя свойств, где он поддержан, определяется resolver endpoint. Семантика отдельного поля установлена по потребителю.
- Единицы: байты всего входа
- Допустимые значения: 0 требует EOF до первого байта; после исчерпания используется peek, поэтому файл ровно по пределу завершается успешно при настоящем EOF. CLI принимает полные десятичные неотрицательные числа, представимые и в uint64_t, и в size_t; это проверяется парсером. Другой собственной проверки скалярного диапазона данного счётчика нет.
- Момент чтения: CLI разрешает поле до файлового ввода; inspect копирует весь профиль в remaining и применяет указанный счётчик/предел при обходе.
- Изменяемость и время жизни: В одном запуске профиль постоянен, остатки расходуются. Новый запуск получает новые значения.
- Ошибка: Неверная десятичная запись или непредставимость собственного значения CLI даёт код 2, usage. При нулевом остатке лишний входной байт даёт код 6, input-limit; ошибка чтения/peek отдельно даёт код 3, read.

### `Limits::frame` — CFG-0823 {#cfg-0823-ru}

- Тип: `std::size_t`. Исходное значение: `= 1048576`
- Источник: явный нативный вход указанного владельца; источник слоя свойств, где он поддержан, определяется resolver endpoint. Семантика отдельного поля установлена по потребителю.
- Единицы: байты тела кадра с идентификатором сообщения
- Допустимые значения: frame≤INT64_MAX и frame≤size_t max−9; 0 локально допустим и оставляет только пустое тело. CLI принимает полные десятичные неотрицательные числа, представимые и в uint64_t, и в size_t; это проверяется парсером. Другой собственной проверки скалярного диапазона данного счётчика нет.
- Момент чтения: CLI разрешает значение до открытия файла; validLimits проверяет представимость. Затем FrameReader получает {frame,frame+9}. Предел также передаётся как размер входных данных/тела строки нижележащим декодерам описаний и данных.
- Изменяемость и время жизни: В одном запуске профиль постоянен, остатки расходуются. Новый запуск получает новые значения.
- Ошибка: Непредставимый предел отклоняется как код 2, стадия=usage до открытия файла. Если считанная длина тела превышает frame, FrameReader сообщает FrameError::BODY_LIMIT, а инспектор завершает работу кодом 6 со стадией framing.2. Для других фактических ошибок кадрирования суффикс равен их числовому FrameError.
- Исходники потребителя: [include/qd/protocol/frame_reader.hpp](../../include/qd/protocol/frame_reader.hpp).
