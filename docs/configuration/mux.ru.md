## DemandLimits {#cfg-0452-owner-ru}

[include/qd/mux/demand.hpp](../../include/qd/mux/demand.hpp)

### `DemandLimits::entries` — CFG-0452 {#cfg-0452-ru}

- Тип: `std::size_t`. Исходное значение: Инициализатора в классе нет. Это не доказывает обязательность ввода; инициализация значением отличается.
- Источник: явный нативный вход указанного владельца; источник слоя свойств, где он поддержан, определяется resolver endpoint. Семантика отдельного поля установлена по потребителю.
- Единицы: различные точные ключи
- Допустимые значения: desired.size() и новый набор неподтверждённой подписки ≤ entries. 0 допускает пустой набор. Совместный размер двух наборов буферов обязан представляться в size_t; create проверяет формулу (max-sizeof(State))/2.
- Момент чтения: Копируется в create и определяет массивы двух наборов буферов; next проверяет desired и каждое изменение ADD/REMOVE.
- Изменяемость и время жизни: Метода изменения лимитов нет; acknowledge изменяет подтверждённый набор в первоначальных пределах.
- Ошибка: Переполнение размеров наборов буферов, превышение desired или нового набора — DemandError::RESOURCE_LIMIT; bad_array_new_length при create также RESOURCE_LIMIT. Остальные ошибки desired проверяются отдельными ветками.
- Исходники потребителя: [include/qd/mux/demand.hpp](../../include/qd/mux/demand.hpp), [src/mux/demand.cpp](../../src/mux/demand.cpp).

### `MuxLimits::schemaRecords` — CFG-0457 {#cfg-0457-ru}

- Тип: `std::size_t`. Исходное значение: Инициализатора в классе нет. Это не доказывает обязательность ввода; инициализация значением отличается.

- Единицы: метаданные записей схемы
- Допустимые значения: Число записей схемы должно быть ≤schemaRecords; 0 допускает только пустую схему. Увеличение самого schemaRecords не меняет размер хранилища и не участвует в его арифметике; для таблицы записей используется фактический records.size().
- Момент чтения: MuxState::create проверяет число записей один раз до расчёта таблиц. Размер записей берётся из records.size(); поздняя команда не перечитывает исходный предел.
- Изменяемость и время жизни: Публичного метода изменения ограничений нет; изменения подписок работают в первоначальном профиле.
- Ошибка: records.size()&gt;schemaRecords даёт MuxError::RESOURCE_LIMIT до расчёта хранения. Последующая ошибка INVALID_CONFIGURATION при расчёте размеров относится к фактическим данным схемы и другим вместимостям; само увеличение schemaRecords её не вызывает.
- Исходники потребителя: [include/qd/mux/interest.hpp](../../include/qd/mux/interest.hpp), [src/mux/interest.cpp](../../src/mux/interest.cpp).

### `MuxLimits::symbolUnits` — CFG-0461 {#cfg-0461-ru}

- Тип: `std::size_t`. Исходное значение: Инициализатора в классе нет. Это не доказывает обязательность ввода; инициализация значением отличается.

Кроме того, рабочая операция рассчитывает visits×symbolUnits с проверкой переполнения и списывает полученную величину из work.symbolUnits. 0 означает нулевую предельную длину и нулевой множитель этой части работы.
- Момент чтения: При create значение только сохраняется. Позднее State::reserve читает его для предварительного расчёта текстовой работы, а проверка ключа — для сравнения длины.
- Изменяемость и время жизни: Публичного метода изменения ограничений нет; изменения подписок работают в первоначальном профиле.
- Ошибка: Слишком длинный проверяемый ключ даёт MuxError::RESOURCE_LIMIT. Непредставимое вычисление visits×symbolUnits в State::reserve также даёт RESOURCE_LIMIT; недостаток уже рассчитанного work.symbolUnits — WORK_LIMIT. В create нет отдельного отказа, зависящего от численного значения symbolUnits.
- Исходники потребителя: [include/qd/mux/interest.hpp](../../include/qd/mux/interest.hpp), [src/mux/interest.cpp](../../src/mux/interest.cpp).
