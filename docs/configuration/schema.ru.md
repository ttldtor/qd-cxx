# Загрузка схем JSON

[English](schema.md) · [Оглавление справочника](../CONFIGURATION-REFERENCE.ru.md)

Контракты потребителей отдельных полей и сведения деклараций/исходников с оговорённой доказательностью явно различаются ниже. НЕИЗВЕСТНО обозначает недостающее сведение. Известные объявленные сведения сохраняются; их семантическая проверка ещё не завершена. Ссылки указывают декларацию или потребителя и не означают нового запуска тестов. Значения описывают текущий API; принятые изменения перечислены в [архитектурном контракте](../CONFIGURATION.ru.md).

- [BinaryJsonSchemaLimits](schema.ru.md#cfg-0667-owner-ru) — `include/qd/schema/json_schema.hpp`
- [JsonSchemaLimits](schema.ru.md#cfg-0664-owner-ru) — `include/qd/schema/json_schema.hpp`

## BinaryJsonSchemaLimits {#cfg-0667-owner-ru}

[include/qd/schema/json_schema.hpp](../../include/qd/schema/json_schema.hpp)

### `BinaryJsonSchemaLimits::loading` — CFG-0667 {#cfg-0667-ru}

- Тип: `JsonSchemaLimits`. Исходное значение: `{}`
- Классификация: составной вход: вложенные типизированные настройки, без новой скалярной единицы. Контракт декларации или исходника, без независимой перепроверки. Семантическая проверка поля и его времени жизни ещё не завершена; запуск runtime-тестов не заявляется.
- Источник: указанная декларация. Явный типизированный вход; псевдоним свойства и отдельный приоритет поля не установлены.
- Объявленное назначение: Полный ввод/depth и исходные core-бюджеты count/name.
- Единицы: НЕИЗВЕСТНО: см. объявленное назначение; дополнительные единицы из типа не выводятся
- Объявленные ограничения: Скалярный диапазон неприменим. Вложенные ограничения или возвращаемые наблюдения сохраняют объявленный смысл.
- Момент чтения: Каждый вызов load*JsonSchema/loadBinaryJsonWireNames: независимые конечные пределы документа, парсера, работы и двух копий.
- Изменяемость и время жизни: Для каждой схемы нужна новая явная загрузка; загрузчик не выполняет файловый I/O, разрешение источников и замену схемы во время работы.
- Ошибка: Перечень ошибок владельца: JsonSchemaError; точное соответствие поля ветви ошибки НЕИЗВЕСТНО и отдельно не установлено.
- Дополнительный перечень ошибок/статусов владельца (без соответствия полю): `JsonSchemaError`.

### `BinaryJsonSchemaLimits::parserBytes` — CFG-0668 {#cfg-0668-ru}

- Тип: `std::size_t`. Исходное значение: `= DEFAULT_BINARY_JSON_PARSER_BYTES`
- Источник: явный нативный вход указанного владельца; источник слоя свойств, где он поддержан, определяется resolver endpoint. Семантика отдельного поля установлена по потребителю.
- Единицы: консервативная оценка байтов, запрашиваемых DOM-парсером
- Допустимые значения: parserRequestBytes(input.size(),min(loading.depth,input.size())+1) ≤ parserBytes; переполнение расчёта тоже отказывает. 0 не вмещает обязательную модель синтаксического анализатора.
- Момент чтения: Функция загрузки получает профиль по значению. Проверки выполняются перед выделением памяти синтаксического анализатора и подготовкой собственной модели схемы.
- Изменяемость и время жизни: Новый вызов может получить другой профиль; готовая LocalSchema неизменяема.
- Ошибка: Нарушение конкретной ресурсной модели — JsonSchemaError::RESOURCE_LIMIT. Ошибочный JSON отдельно MALFORMED_JSON; память, которую допустила модель, может дать ALLOCATION_FAILURE.
- Исходники потребителя: [include/qd/schema/json_schema.hpp](../../include/qd/schema/json_schema.hpp), [src/schema/json_schema.cpp](../../src/schema/json_schema.cpp).

### `JsonSchemaLimits::depth` — CFG-0665 {#cfg-0665-ru}

- Тип: `std::size_t`. Исходное значение: `= 16`
- Источник: явный нативный вход указанного владельца; источник слоя свойств, где он поддержан, определяется resolver endpoint. Семантика отдельного поля установлена по потребителю.
- Единицы: уровни вложенных JSON контейнеров
- Допустимые значения: depthFits увеличивает глубину на структурных { и [ вне строк, включая пустые контейнеры; попытка нового уровня при depth==limit отвергается. Скобки внутри JSON-строк не учитываются. parserDepth=min(depth,input.size())+1 включает служебный учёт. 0 запрещает структурный контейнер.
- Момент чтения: depthFits перед разбором отслеживает вложенность объектов и массивов: только { и [ вне JSON-строк увеличивают глубину. Внутри строки учитываются кавычки и экранирование, скобки игнорируются. Проверку корректности JSON затем выполняет simdjson.
- Изменяемость и время жизни: Новый вызов может получить другой профиль; готовая LocalSchema неизменяема.
- Ошибка: Нарушение конкретной ресурсной модели — JsonSchemaError::RESOURCE_LIMIT. Ошибочный JSON отдельно MALFORMED_JSON; память, которую допустила модель, может дать ALLOCATION_FAILURE.
- Исходники потребителя: [include/qd/schema/json_schema.hpp](../../include/qd/schema/json_schema.hpp), [src/schema/json_schema.cpp](../../src/schema/json_schema.cpp).
