Известные объявленные сведения сохраняются; их семантическая проверка ещё не завершена. Ссылки указывают декларацию или потребителя и не означают нового запуска тестов. Значения описывают текущий API; принятые изменения перечислены в [архитектурном контракте](../CONFIGURATION.ru.md).

### `CandleRouteLimits::records` — CFG-0311 {#cfg-0311-ru}

- Тип: `std::size_t`. Исходное значение: Инициализатора в классе нет. Это не доказывает обязательность ввода; инициализация значением отличается.
- Источник: явный нативный вход указанного владельца; источник слоя свойств, где он поддержан, определяется resolver endpoint. Семантика отдельного поля установлена по потребителю.
- Единицы: ID физических записей маршрутов
- Допустимые значения: recordIds.size()&lt;=records до анализа каждого ID. Ноль допускает пустой набор входных ID; корректность и дубликаты проверяются отдельно.
- Момент чтения: PreparedCandleRoutes::prepare проверяет число записей списка и расходует records только при подготовке таблицы. Готовая таблица этот предел не сохраняет.
- Изменяемость и время жизни: Поле расходуется только при prepare и не сохраняется PreparedCandleRoutes. Следующий prepare может передать другие ограничения; готовый набор хранит entries и отдельный symbolUnits.
- Ошибка: std::expected: CandleRouteFailure{CandleRouteError::RESOURCE_LIMIT,recordId?,...}; bad_alloc/length_error → ALLOCATION_FAILURE; грамматика/маршрут имеют отдельные причины.
- Исходники потребителя: [include/qd/events/candle_routes.hpp](../../include/qd/events/candle_routes.hpp), [src/events/candle_routes.cpp](../../src/events/candle_routes.cpp).

### `CandleRouteLimits::symbolUnits` — CFG-0313 {#cfg-0313-ru}

- Тип: `std::size_t`. Исходное значение: Инициализатора в классе нет. Это не доказывает обязательность ввода; инициализация значением отличается.

- Единицы: кодовые единицы UTF-16 физического символа Candle
- Допустимые значения: Один сохранённый предел symbolUnits применяется в четырёх точках: логический вход resolve, его физический результат, физический вход restore и восстановленный логический результат. Каждая соответствующая длина UTF-16 должна быть&lt;=symbolUnits. Ноль пропускает только пустую длину через этот тест; грамматика символа отдельно может отвергнуть её.
- Момент чтения: prepare сохраняет symbolUnits вместе с entries. resolve и restore читают его до преобразования входа и повторно после получения результата.
- Изменяемость и время жизни: Предел хранится в PreparedCandleRoutes и действует на все последующие resolve/restore этого набора. Другой prepare создаёт независимый набор с новым пределом.
- Ошибка: std::expected: CandleRouteFailure{CandleRouteError::RESOURCE_LIMIT,recordId?,...}; bad_alloc/length_error → ALLOCATION_FAILURE; грамматика/маршрут имеют отдельные причины.
- Исходники потребителя: [include/qd/events/candle_routes.hpp](../../include/qd/events/candle_routes.hpp), [src/events/candle_routes.cpp](../../src/events/candle_routes.cpp).

### `CandleRouteLimits::mapping` — CFG-0314 {#cfg-0314-ru}

- Источник: указанная декларация. Явный типизированный вход; псевдоним свойства и отдельный приоритет поля не установлены.
- Объявленное назначение: Пределы работы подготовки и хранилища mapper для каждого кандидата.

- Объявленные ограничения: Скалярный диапазон неприменим. Вложенные ограничения или возвращаемые наблюдения сохраняют объявленный смысл.
- Момент чтения: Явный параметр публичных операций: [[nodiscard]] static std::expected&lt;PreparedCandleRoutes, CandleRouteFailure&gt; prepare(const core::LocalSchema &amp;schema, std::span&lt;const std::int32_t&gt; recordIds, CandleRouteLimits limits)
- Изменяемость и время жизни: Момент чтения и владение определяются публичным контрактом владельца; общей гарантии замены во время работы нет. Время жизни конкретного поля отдельно не перепроверено.
- Ошибка: Перечень ошибок владельца: CandleRouteError; точное соответствие поля ветви ошибки НЕИЗВЕСТНО и отдельно не установлено.
- Дополнительный перечень ошибок/статусов владельца (без соответствия полю): `CandleRouteError`.

- Изменяемость и время жизни: Параметры задают допуск одного AttachmentCodecRegistry::create. Результат хранит независимые копии регистраций; создание нового реестра может использовать другие лимиты. Вызов декодера получает отдельные AttachmentDecodeLimits.
- Ошибка: Превышение объявленного состояния или учитываемого памяти, учитываемой распределителем возвращает AttachmentError::RESOURCE_LIMIT.
