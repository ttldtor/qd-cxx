# Воспроизведение

[English](replay.md) · [Оглавление справочника](../CONFIGURATION-REFERENCE.ru.md)

Контракты потребителей отдельных полей и сведения деклараций/исходников с оговорённой доказательностью явно различаются ниже. НЕИЗВЕСТНО обозначает недостающее сведение. Известные объявленные сведения сохраняются; их семантическая проверка ещё не завершена. Ссылки указывают декларацию или потребителя и не означают нового запуска тестов. Значения описывают текущий API; принятые изменения перечислены в [архитектурном контракте](../CONFIGURATION.ru.md).

### `ReplayLimits::reader` — CFG-0632 {#cfg-0632-ru}

- Тип: `protocol::TapeLimits`. Исходное значение: Инициализатора в классе нет. Это не доказывает обязательность ввода; инициализация значением отличается.
- Классификация: составной вход: вложенные типизированные настройки, без новой скалярной единицы. Контракт декларации или исходника, без независимой перепроверки. Семантическая проверка поля и его времени жизни ещё не завершена; запуск runtime-тестов не заявляется.
- Источник: указанная декларация. Явный типизированный вход; псевдоним свойства и отдельный приоритет поля не установлены.
- Объявленное назначение: Независимые бюджеты разбора и хранения свежего reader.
- Единицы: НЕИЗВЕСТНО: см. объявленное назначение; дополнительные единицы из типа не выводятся
- Объявленные ограничения: Скалярный диапазон неприменим. Вложенные ограничения или возвращаемые наблюдения сохраняют объявленный смысл.
- Момент чтения: Явный параметр публичных операций: [[nodiscard]] ReplayResult replayTape(const protocol::AdmittedTape &amp;tape, ReplayObserver &amp;observer, ReplayClock &amp;clock, ReplayCancellation &amp;cancellation, ReplayLimits limits, ReplayPolicy policy)
- Изменяемость и время жизни: Момент чтения и владение определяются публичным контрактом владельца; общей гарантии замены во время работы нет. Время жизни конкретного поля отдельно не перепроверено.
- Ошибка: Перечень ошибок владельца: ClockError; точное соответствие поля ветви ошибки НЕИЗВЕСТНО и отдельно не установлено.
- Дополнительный перечень ошибок/статусов владельца (без соответствия полю): `ClockError`.

### `ReplayLimits::deliveredRecords` — CFG-0633 {#cfg-0633-ru}

- Тип: `std::size_t`. Исходное значение: Инициализатора в классе нет. Это не доказывает обязательность ввода; инициализация значением отличается.
- Источник: явный нативный вход указанного владельца; источник слоя свойств, где он поддержан, определяется resolver endpoint. Семантика отдельного поля установлена по потребителю.
- Единицы: успешно доставленные записи
- Допустимые значения: Перед следующей записью deliveredRecords &lt; лимита; 0 прекращает работу перед первым onRecord.
- Момент чтения: ReplaySession копирует ReplayLimits на синхронный запуск; значения читаются непосредственно перед попыткой работы/вызова.
- Изменяемость и время жизни: Внутри запуска неизменяемы; новый запуск получает новый профиль.
- Ошибка: Достижение deliveredRecords до следующего onRecord даёт ReplayOutcome::RESOURCE_LIMIT, стадия=delivered-records; следующий обработчик записи не вызывается.
- Исходники потребителя: [include/qd/replay/tape_replay.hpp](../../include/qd/replay/tape_replay.hpp), [src/replay/tape_replay.cpp](../../src/replay/tape_replay.cpp).

- Исходники потребителя: [include/qd/replay/tape_replay.hpp](../../include/qd/replay/tape_replay.hpp), [src/replay/tape_replay.cpp](../../src/replay/tape_replay.cpp).

### `ReplayLimits::workUnits` — CFG-0635 {#cfg-0635-ru}

- Тип: `std::size_t`. Исходное значение: Инициализатора в классе нет. Это не доказывает обязательность ввода; инициализация значением отличается.
- Источник: явный нативный вход указанного владельца; источник слоя свойств, где он поддержан, определяется resolver endpoint. Семантика отдельного поля установлена по потребителю.
- Единицы: совокупные попытки работы воспроизведения
- Допустимые значения: Каждый charge требует workUnits остаток и не возвращает его при ошибке пользовательского кода; 0 не допускает первую рабочую попытку.
- Момент чтения: ReplaySession сохраняет общий workUnits на запуск. Каждый опрос, вызов часов, ожидание, посещение исходящего описания, попытка записи/кадра и обработчик передают собственную стадию в charge/callCharge.
- Изменяемость и время жизни: Внутри запуска неизменяемы; новый запуск получает новый профиль.
- Ошибка: Исчерпание workUnits возвращает ReplayOutcome::RESOURCE_LIMIT со стадией попытки: cancellation-work, clock-calls, wait-calls, layout-work, record-work, frame-work или callback-calls. charge/callCharge проверяют кредит до соответствующего вызова или посещения; уже выполненная работа сохраняется в счётчиках.
- Исходники потребителя: [include/qd/replay/tape_replay.hpp](../../include/qd/replay/tape_replay.hpp), [src/replay/tape_replay.cpp](../../src/replay/tape_replay.cpp).
