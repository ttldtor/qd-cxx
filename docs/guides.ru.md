| Задача | Руководство | Когда выбирать |
| --- | --- | --- |
| Разбирать торговые часы инструмента | [Правила расписаний](SCHEDULE-RULES.ru.md) | Полная закреплённая грамматика, именованные площадки и типизированные defaults в явных ограниченных контекстах; [консольный пример](../examples/schedule_rules/README.ru.md) |
| Получать типизированные live-события | [Публичный feed API](FEED-API.ru.md) | Продвижение библиотекой, подписки Quote/Profile и обычный TCP; [полный пример](../examples/feed_quote/README.ru.md) |
| Встроить в существующий хост | [Владение bootstrap runtime](../spec/transport/RUNTIME-EMBEDDING.ru.md) | Требования startup и время жизни явно заимствованного bootstrap |
| Хранить метаданные инструмента | [Значения instrument profile](INSTRUMENT-PROFILES.ru.md) | Владеющие стандартные/пользовательские поля и типизированные преобразования без I/O |
| Разбирать региональные символы | [Помощники рыночных символов](MARKET-SYMBOLS.ru.md) | Точная композиция базы/кода UTF-16 без маршрутизации подписок |
| Читать бинарные tape | [Анализ tape](TAPE-INSPECT.ru.md) | Вход — готовый файл; выбирается поддержанный конечный профиль источника |
| Записывать tape | [Запись tape](TAPE-WRITE.ru.md) | У вас уже есть проверенные записи и явная схема |
| Анализировать кадры протокола | [Анализ QTP](QTP-INSPECT.ru.md) | Нужна автономная диагностика кадров и записей |
| Читать события Profile | [Анализ Profile](PROFILE-INSPECT.ru.md) | Требуется поддержанное отображение Profile |

| Экспортировать схему Java | [Экспорт схем](../tools/schema-export/README.ru.md) | Нужна экспортированная схема из закреплённого Java QD |
| Получать контролируемый STREAM | [Подписки STREAM](SUBSCRIPTIONS.ru.md) | Достаточно контролируемого plain-TCP peer и точных селекторов |
| Собрать приложение STREAM | [Программный пример](../examples/subscriptions/README.ru.md) | Приложение само продвигает runtime и вызывает callbacks |

STREAM-программа имеет конечную границу остановки и использует обычный TCP. Отдельный TLS runtime
имеет собственный [контракт доверия, идентичности, учётных данных и времени жизни](../spec/transport/TLS-RUNTIME.ru.md);
сохранение настройки TLS в endpoint не превращает обычную программу в TLS-клиент. Переподключение
и полный фасад общих подписок относятся к отдельным возможностям. Перед интеграцией проверьте
[текущую поддержку](CURRENT-STATE.ru.md).

- [Источники индексированных событий и заявок](EVENT-SOURCES.ru.md): значения ID/имён без маршрутизации подписок.

- [CFI и дополнительные базовые активы](GLOSSARY-VALUES.ru.md): `qd/glossary/`, необязательная `qdcxx_ipf`.

- [Ценовые шаги инструмента](PRICE-INCREMENTS.ru.md): диапазоны, точность и округление цены через `qdcxx_ipf`.

- [Коллектор живых профилей](IPF-COLLECTOR.ru.md): владеющие ревизии, удаления и безопасные callbacks слушателей.

- [Live-подключения профилей](IPF-CONNECTION.ru.md): фоновая доставка, явный worker runtime и безопасный close.

- [Вывод текста событий/значений](EVENT-TEXT.ru.md): явный контекст, точный UTF-16 и готовый UTF-8; [консольный пример](../examples/event_text/README.ru.md).
