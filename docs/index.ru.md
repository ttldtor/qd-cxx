# Документация qd-cxx {#documentation-ru}

Русский · [English](index.md)

Используйте qd-cxx как библиотеку C++23 или через утилиты автономного анализа. Реализовано подмножество
кодировок, записей, tape и контролируемых транспортных профилей QD. Начните с нужной операции;
[возможности и ограничения](CURRENT-STATE.ru.md) определяют поддержанные профили.

1. **[Начало работы](getting-started.ru.md)** — собрать и установить библиотеку, запустить небольшой потребитель.
2. **[Практические руководства](guides.ru.md)** — получать рыночные данные, запрашивать снимки, работать с инструментами и читать tape.
3. **[Справочник API](api.ru.md)** — найти заголовки, цели линковки, условия владения и ошибки.
4. **[Архитектура и протоколы](../spec/README.ru.md)** — разобраться в компонентах и поведении на проводе.

[Документация разработчика](developer.ru.md) содержит параметры сборки, профили проверок и результаты
conformance-тестов. [Политика совместимости](COMPATIBILITY.ru.md) объясняет, какое поведение Java QD сохраняет библиотека.

- [Дни и сессии Schedule](SCHEDULE-QUERIES.ru.md): владеющие снимки поколений, calendar queries, лимиты и actual oracle.
- [Явные timezone-данные](TIME-ZONE-DATA.ru.md): shared CORE binding, optional backend, закреплённая offline-зависимость и перенос.
