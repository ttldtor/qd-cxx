# События OptionSale

`events::OptionSale` владеет данными сделки опциона, связанной с символом базового инструмента. Используйте `Feed::createSubscription<events::OptionSale>()` с endpoint HISTORY. Стандартный реестр HISTORY включает это событие и поддерживает индексный источник по умолчанию. Символ сохраняется целиком, включая суффикс, похожий на обозначение биржи. Положительный идентификатор источника не выбирает маршрут OptionSale.

Индекс `Index` определяет событие при индексной доставке и удалении. Независимые поля `Time` и `Sequence` описывают время сделки. `eventFlags` содержит флаги индексной доставки, а `flags` — свойства сделки. Событие владеет строками и остальными значениями. `OptionSymbol` сохраняет отдельно отсутствие значения и пустую строку.
