# Цепочки опционов из instrument profiles

[English](OPTION-CHAINS.md). Английская версия является основной.

Включите `ORG_TTLDTOR_QDCXX_BUILD_IPF=ON` и подключите установленную цель `qdcxx_ipf`.
Самодостаточный публичный заголовок — `qd/ipf/option_chains.hpp`. Feed, runtime, TLS,
сеть и приватные заголовки не нужны. При отключённом IPF цель и её заголовки не
устанавливаются. Существующая `qdcxx_feed` не зависит от этого необязательного компонента.

`OptionChainsBuilder::build(profiles)` группирует профили по порядку входа. `addProfile`
возвращает `true` при добавлении/замене, `false` при пропуске или `OptionChainError`.
[Точная спецификация](../spec/ipf/OPTION-CHAINS.ru.md) определяет правила группировки.
Полный компилируемый пример находится в [английском руководстве](OPTION-CHAINS.md).

Скопированная карта владеет неизменяемыми цепочками. Цепочки владеют сериями и картами
strike; ячейки разделяют неизменяемые **копии** принятых профилей. Изменение/уничтожение
входа и последующие изменения builder не меняют сохранённый снимок. Это осознанное
отличие от изменяемых разделяемых ссылок Java. `getChains()` возвращает заимствованную
карту: скопируйте её перед изменением/уничтожением builder. Ссылки через сохранённую
цепочку действуют, пока сохраняется владение цепочкой. Копии builder развиваются независимо;
после перемещения источник пуст и пригоден для повторного использования с прежними лимитами.

Метаданные и strike сохраняют порядок Java. Внешняя карта имеет детерминированный порядок
UTF-16 символов, поскольку Java `HashMap` не гарантирует порядок.
`getStrikes()` и `getNStrikesAround(count, center)` возвращают независимые векторы.
Выборка сохраняет Java-позицию вставки и усечение справа, допускает неограниченные
и NaN-центры, возвращает `INVALID_COUNT` для отрицательного количества.

`OptionChainLimits` копируется один раз. Значения по умолчанию: 100 000 просмотренных
профилей, 4 096 цепочек, 16 384 серии, 200 000 call/put-ячеек, 16 777 216 удерживаемых
единиц UTF-16, консервативный временный объём 50 331 648 единиц и 1 073 741 824 накопленных
логических единиц работы. Обычные вызовы не требуют обслуживания бюджетов. Другие
конечные лимиты задаются в конструкторе или `build`.

Отказ не меняет цепочки и счётчики, в том числе при исключении выделения памяти.
Исключения выделения памяти передаются вызывающему коду. Превышение лимита возвращает
`LIMIT_EXCEEDED`; ограничения доступа к числовым/датовым полям исходного профиля —
`PROFILE_ACCESS`. Пропущенные входы расходуют лимиты количества и просмотра. Копии
сохраняют собственные лимиты профиля. Изменяемый builder требует внешней синхронизации;
опубликованные неизменяемые снимки допускают параллельное чтение.

Полная валидация CFI, разбор дополнительных базовых активов и шаги цены — отдельные API.
Компонент проверяет только префикс `OC`/`OP`, сохраняя остальной текст серии.
[Production Java oracle](../tools/upstream/option-chains-oracle/README.ru.md) и
[fixtures](../tests/fixtures/option-chains/README.ru.md) фиксируют эту границу совместимости.
