## Одна предлагаемая следующая задача реализации (не назначена)

**Ограниченный binary tape reader без сжатия с qdcxx-tape-inspect.** Новый ID задачи не назначается.
Это конкретное предложение для назначения владельцем, а не разрешение в рамках QDCXX-020.

Цель: прочитать точный constrained-файл QDCXX-019, не удаляя header/footer и не перемещая
поздние descriptions. Входы: неизменяемая локальная схема обычного типа 8 от вызывающей стороны,
hasTime=false, BINARY/без сжатия/time NONE/EMPTY_SET/STREAM_DATA/нулевые raw-флаги. Использовать
нынешние примитивы/bindings; IO/CLI оставить вне qdcxx_core, точное поведение/вывод qdcxx-qtp-inspect сохранить.

До C++: получить узкие доказательства Java production-parser для вариантов descriptor, неизвестных
свойств, отсутствующих/повторных/переопределённых ID, позднего добавления, malformed/truncated
header/description/data и EOF. Проверить ADR с правилами descriptor (version как диагностика,
time/opt/send sets), единственного начального header, только добавляемых ID/владения планами,
ошибок с завершённым префиксом и политики пустого файла/footer. Изменения протокола сопровождаются
спецификацией и фикстурами.

Границы реализации: конечные бюджеты файла/кадров/descriptions/записей/полей/символов/вывода,
явные терминальные ошибки, без замены ID и общего session reset. Один опциональный executable
qdcxx-tape-inspect с явным профилем; собственный контракт вывода/ошибок, без совместимости CLI Java.
Без аргументов и standalone --help должны совпадать: stdout, пустой stderr/exit 0, без файлового IO;
неверные непустые аргументы и ошибки вывода сохраняют ненулевой код. Новые средства приёмки не добавляют Python.

Приёмка: неизменённый положительный constrained-вход QDCXX-019 и сохранённые хеши; узкие Java
positive/negative Verify с двумя чистыми захватами; C++ conformance и process/help/IO/budget/error
tests; явное отклонение времени default-BINARY/TEXT/неподдерживаемых типов; production
BUILD_TESTING=OFF без тестовых зависимостей; применимые проверки форматирования/сборки и
парная валидация EN/RU. Сохранить старые синтетические фикстуры. Для первого реального события
позднее обязательна приёмка Quote.

Исключены compression/sidecars/follow/rotation/retention/resync, MESSAGE/FIELD time, RAW/TICKER/HISTORY,
подписки/ненулевые флаги, writer/сеть, преобразование типов, importer и поддержка схем реальных событий.
Новая runtime-зависимость требует явного одобрения. Если ADR требует более широкой семантики,
сузить или разделить задачу до реализации, не расширять профиль молча.

Решения владельца: одобрить эту ограниченную реализацию и новый executable/контракт вывода;
отдельно одобрять собственный CLI/конфигурацию каждой утилиты по перечню. Адаптер/публичный API
Quote, более широкие преобразования и транспорт/потоки остаются последующими решениями.
Исследование их не разрешает.
