# События опционных серий

[English version](SERIES-EVENT.md). При расхождении применяется английский текст.

[Series](../include/qd/events/series.hpp) владеет расчётными значениями одной
опционной серии базового символа. Несколько серий могут иметь одинаковую дату
экспирации. Их различает индекс. Источник всегда `IndexedEventSource::DEFAULT` (ID 0).

| Поле | Значение |
| --- | --- |
| Символ и индекс | Точный символ базового инструмента и идентификатор серии в пределах символа. Публичный индекс расширяет знаковое 32-битное значение протокола до знакового 64-битного значения. |
| Флаги события | Флаги снимка, транзакции и удаления из индексированной доставки. |
| Время события | Независимая метка в миллисекундах Unix при выборе метаданных FIELD, иначе ноль. |
| Время и последовательность | Время опционной серии и младшие 22 бита последовательности из `Time` и `Sequence`. |
| Экспирация | Знаковый идентификатор дня, число дней от 1970-01-01. |
| Волатильность | Индекс подразумеваемой волатильности. |
| Объёмы call и put | Дневные объёмы торгов опционами call и put. `getOptionVolume()` складывает имеющиеся значения и возвращает NaN, если оба значения равны NaN. |
| Отношение put/call | Отношение объёма торгов опционами put к объёму call. |
| Форвардная цена | Подразумеваемая форвардная цена. |
| Дивиденд и процент | Подразумеваемые простые дивидендная и процентная доходности. |

Владеющее значение сохраняет проекцию wide decimal и значение `double`.
После изменения открытого десятичного поля метод возвращает его текущее значение.

Стандартная запись называется `Series`. В логической схеме физический префикс
VOID/Index представляет поле `Index`. Ключ коллектора хранит беззнаковое
младшее слово. При удалении старшее слово также может быть ненулевым. В обоих
случаях публичный индекс отражает знаковое младшее слово. Экспирация и время
опционной серии не участвуют в индексации.

`PreparedSeries` принимает явно выбранную запись из проверенной пользовательской
схемы. Обязательны `Expiration`, `Volatility`, `PutCallRatio` и `ForwardPrice`.
Отсутствующие `Index`, `Time` и `Sequence` равны нулю. Отсутствующие `CallVolume`,
`PutVolume`, `Dividend` и `Interest` равны NaN. Для индексированной подписки
также нужна проверенная индексируемая схема, в которой `Index` задаёт младшее слово.

Перед преобразованием mapper проверяет все поля и идентификатор схемы и записи.
Полученное событие владеет символом и значениями независимо от схемы, mapper
и исходного курсора.
