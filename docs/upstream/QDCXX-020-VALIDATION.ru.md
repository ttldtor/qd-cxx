# Проверки QDCXX-020 и передача на ревью

[English](QDCXX-020-VALIDATION.md). Английская версия является основной.

Дата: 2026-09-22 UTC. Только исследование/документация; без production-кода, зависимостей, нового
Python, изменений фикстур/lock и коммита. Для задачи только с документами C++-матрица не требуется.

## Результаты и рекомендация

- [QDS-TOOLS](QDS-TOOLS.ru.md): 20 зарегистрированных команд, написания без учёта регистра,
  dispatch/help, упаковка, делегирование IPF и отдельный MICBuilder, приоритеты/предложения совместимости.
- [REAL-EVENT-BASELINE](../REAL-EVENT-BASELINE.ru.md): неизменённый стандартный составной Quote,
  восемь полей / двенадцать int-слотов Java, типы 56/2/120; предложение теста через production-файл
  по исходникам, не захват.
- [PYTHON-MIGRATION](../PYTHON-MIGRATION.ru.md): обязательные CLI-тесты и ручные/исторические процессы,
  места замены, эквивалентность отрицательных проверок и архивная политика.
- [NEXT-STEPS](../NEXT-STEPS.ru.md): одна неназначенная следующая реализация — ограниченный binary
  tape reader без сжатия с опциональным qdcxx-tape-inspect, затем реальный Quote и рабочие утилиты.

Решения владельца предложены конкретно, но ещё не приняты: ADR tape descriptor/добавления bindings/EOF,
новый executable/контракт вывода, совместимость CLI/конфигурации каждой утилиты; позднее адаптер/API
Quote и транспорт/подписки. ID задач после QDCXX-020 не назначались.

## Ограничения справки и выполнения

Java dispatcher и справка отдельных команд не запускались/не захватывались: полный runtime
утилит недоступен; help может создавать провайдеры, обычный запуск вызывает Services.startup.
Вместо этого изучены статьи, аннотации, опции, fallback и startup-путь. Не выполнялись обращения
к внешним потокам, открытие listeners, публикация, ротация/удаление или изменение настроек.
В QDCXX-020 не запускались новые захваты Java event/tape, clean upstream build, Python-скрипты
или C++-тесты. Прежние runtime-результаты QDCXX-019 приведены как история, не повторены независимо здесь.

## Независимое ревью

Отдельный агент `independent_review` выполнил read-only ревью исходников, не авторскую валидацию.
Первый проход независимо проверил SHA, все 20 регистраций, help/dispatch/упаковку, MICBuilder,
defaults/типы/слоты/delegates Quote и пути Python CMake/логирования/получения инструментов.
Проверены 80 закреплённых ссылок / 39 уникальных путей upstream первых двух пар документов;
отсутствующих нет. EN/RU QDS-TOOLS, REAL-EVENT-BASELINE и PYTHON-MIGRATION прочитаны без
существенных расхождений перевода. Ревьюер не запускал Java/Python/C++/сеть и не менял файлы.

Первичные замечания: пропущена Compare --collector/-c (P2), путь TDP «готовый profile → file+"~"»
и поглощённый IOException (P2), не указан тип результата Invoke void по умолчанию (P3).
Автор исправил все три в EN/RU, а также уточнил написание NetTest --rate-limit по исходникам.
Второй независимый проход проверил итоговые план/статус/валидацию и исправления, повторил
проверки 18 документов/326 относительных ссылок, whitespace tracked/новых файлов, защищённых
путей/отсутствия нового Python и не нашёл новых замечаний. Порядок tape-first признан обоснованным
ограниченным предложением, отдельным от последующего Quote и требующим назначения владельцем.

Автор дополнительно исправил различие локальных имён схемы с точками и исходящих имён свойств,
а также описал поддержку wide decimal прямым файловым путём независимо от EMPTY_SET.
Ревьюер независимо сверил AbstractDataField/DefaultRecord/QuoteMapping/BinaryRecordDesc,
FileFormat/BinaryQTPComposer, EN/RU и все 88 закреплённых ссылок / 43 уникальных пути:
отсутствующих путей и новых замечаний нет. Ревью завершено, три исходных замечания закрыты.
Итоговый статус и запись результатов внесены автором после ревью. В указанных проверках ошибок
не обнаружено; это не общая гарантия семантической/runtime-совместимости.
