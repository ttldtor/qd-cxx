# Ордера OTC и аукционный дисбаланс

[English](AUCTION-ORDER-EVENTS.md).

`OtcMarketsOrder` — владеющее индексируемое событие из `qd/events/otc_markets_order.hpp`.
В `order` хранятся все общие свойства ордера. Старшие 32 бита индекса содержат ID источника
из имени записи, младшие 32 бита — беззнаковое представление поля `Index`. Событие сохраняет
знаковое значение платы за доступ к котировке и полные флаги OTC. Положительное значение
означает скидку, отрицательное — плату, ноль — отсутствие платы и скидки. Метод получения
типа цены отображает зарезервированный код 3 в `UNPRICED`. Флаги индексируемой доставки,
общие флаги ордера и флаги OTC независимы. Логическая схема по умолчанию содержит
`OtcMarketsOrder` и `OtcMarketsOrder#pink` с обычным младшим индексным полем HISTORY.

`OrderImbalance` — владеющее событие TICKER с источником из `qd/events/order_imbalance.hpp`.
Источник определяется по имени записи. Событие содержит упакованные знаковое время
и последовательность, пять числовых свойств и полные флаги аукциона. Методы получения
стороны и типа аукциона отображают зарезервированные коды в `UNDEFINED`. Отсутствующее время
или последовательность даёт ноль в соответствующей части упакованного значения.
Отсутствующие ближняя и дальняя цены представлены как NaN. Логическая схема по умолчанию
содержит запись без суффикса и варианты `#NTV`, `#ARCA` и `#NUAM`. Каждый вариант может
независимо сообщать данные для одного и того же базового символа.

При подготовке преобразователя укажите ID записи в проверенной локальной схеме. Имя семейства
и суффикс источника проверяются при подготовке. Пользовательская схема может задавать порядок
полей и выбирать поддерживаемые числовые представления. Возможность публикации для источника
не ограничивает преобразование явно присутствующей записи при приёме. Оба преобразователя
проверяют контекст и полный набор полей перед созданием владеющего события. Оба принимают
независимое время события FIELD в миллисекундах, по умолчанию ноль. Бюджеты UTF-16 применяются
перед сохранением символа или имени маркетмейкера.

[Описание оракула](../tools/upstream/auction-order-oracle/README.ru.md) перечисляет сравнения
QTP и делегатов для профилей по умолчанию, tiny-decimal, целочисленного и полной книги заявок.
