# Architecture decision records

Use this directory for decisions that materially constrain architecture, compatibility, dependencies, concurrency, ownership, or public API.

Name records `ADR-NNNN-short-title.md`. Each record should include status, context, decision, alternatives, consequences, compatibility impact, and links to evidence or tasks. Do not create an ADR merely to repeat an implementation detail that is easy to reverse.
