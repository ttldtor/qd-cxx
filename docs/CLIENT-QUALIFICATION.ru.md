# Проверка принимающего клиента {#receiving-client-qualification-ru}

[English version](CLIENT-QUALIFICATION.md). Английская версия является основной.

Начните с [примера установленного Feed](../examples/feed_quote/README.ru.md) и выберите маршрут приёма в [матрице возможностей и протокола](CLIENT-CAPABILITIES.ru.md). Для каждого контракта матрица указывает детерминированные проверки и проверки на зафиксированных данных Java.

| Область | Наблюдаемый результат | Проверка |
| --- | --- | --- |
| Feed и жизненный цикл | Доставка типизированного Quote, наблюдение состояния и статистики, завершение работы и освобождение захваченных объектов | [Feed API](FEED-API.ru.md), `feed_api`, `client_dispatch`, `mux_queue` |
| Рыночные и исторические примеры | Вывод рыночных событий, ограниченные запросы истории и последних событий, независимые результаты моделей | [Рыночный пример](../examples/feed_market/README.ru.md), [пример запросов](../examples/client_queries/README.ru.md), [пример моделей](../examples/client_models/README.ru.md) |
| Управление источником | Локальный бинарный тейп и конечное воспроизведение OnDemand, скорость и пауза, очистка или явный переход на живой источник | `tape_feed`, `on_demand_feed`, [профиль OnDemand](../spec/transport/ON-DEMAND-ACCESS.ru.md) |
| Защищённый пакет | Проверенный TLS и настроенный QTP Basic, отказ при неверном сертификате доверия или имени, сборка без OpenSSL при выключенном TLS | [Сборка и установка](CPP-BUILD.ru.md), `feed_tls`, [внешний TLS-потребитель](../tests/conformance/feed_tls_consumer/CMakeLists.txt) |

На Windows используйте MSVC Release, на Linux — GCC Debug с ASan и UBSan. В проверочном профиле Linux отключено обнаружение утечек. Установите SDK по [инструкции сборки](CPP-BUILD.ru.md), настройте внешний проект с путём установки и повторите проверку после переноса каталога SDK. Проверьте вывод примера и отсутствие прежнего пути установки. На Windows проверьте оба порядка включения заголовков SDK в тесте установленного пакета.

Для проверки OnDemand используются ограниченный профиль loopback и зафиксированные тестовые данные. Доступ и совместимость с внешним поставщиком воспроизведения проверяются отдельно.
