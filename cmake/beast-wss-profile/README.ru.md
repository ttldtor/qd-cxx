# Профиль зависимостей Beast WSS

[English version](README.md). Английская версия нормативная.

Отдельный профиль устанавливает заголовки Boost, необходимые внутренней цели сборки WSS. Проба компилирует и компонует поток TCP на Boost.Asio, поток OpenSSL и поток WebSocket на Beast. Так проверяется граф зависимостей. Поведение TLS-сессии, сертификатов и ввода-вывода WebSocket проверяется отдельно.

Манифест включает 940 файлов, в том числе оригинальную Boost Software License 1.0 и заголовок версии. Набор заголовков — объединение списков зависимостей MSVC и GCC для [пробы](../../tests/conformance/beast-wss-dependency/probe.cpp) с определениями цели. Если адаптеру понадобятся дополнительные заголовки или определения, расширьте набор и повторите обе сборки. Версия, точный хеш архива и хеш перечня файлов зафиксированы в [профиле](boost-1.92.0.json) и [манифесте](boost-1.92.0-sources.sha256.tsv).

Цель использует заголовочные Beast и Boost.Asio с отключённой автолинковкой библиотек Boost. Windows выбирает определения API Windows 10, исключает макросы min/max из Win32 и линкует Winsock. На обеих платформах цель линкует квалифицированный статический SDK OpenSSL 3.5.9, который явно выбирает потребитель. SDK проверяется до линковки. Пути включения и определения Boost применяются к целям, которые линкуют внутренний пакет. Цели QTP используют действующий профиль исходников standalone Asio. [Профиль OpenSSL](../tls-profile/openssl-3.5.9.json)

Выполните настройку, сборку, установку и проверку перенесённой копии по [руководству подготовки](../../tools/deps/BEAST-WSS.ru.md).

[Граница и локальная проверка TLS](../../spec/transport/BEAST-WSS-TLS.ru.md) охватывают владение, проверку сертификатов, фиксированные буферы и отмену.
