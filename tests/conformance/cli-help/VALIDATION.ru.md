# Валидация справки при запуске без аргументов

[English version](VALIDATION.md). Английский документ является основным.

Политика CLI по запросу владельца: отсутствие аргументов использует тот же путь кода и байты,
что отдельный `--help`: stdout, пустой stderr, exit 0 при успешном выводе. Непустые неверные/неполные
аргументы остаются usage exit 2. Ошибка write/flush справки остаётся I/O exit 3. Текущая пользовательская
qdcxx-утилита — QTP-инспектор; AGENTS.md закрепляет правило для будущих qdcxx-утилит. Внутренние
операционные скрипты/test runners сохраняют свои документированные контракты запуска.

Проверки автора выполнены 2026-09-22 UTC:

- MSVC Release: сборка и все 10 suites.
- WSL GCC Release: сборка и все 10 suites.
- Инспектор пользователя в `cmake-build-debug` пересобран с его существующей конфигурацией MSVC/Ninja.
- Закреплённые Uncrustify → clang-format: Format и Check.
- Прямое сравнение no-argument/--help для executable пользователя, хеши fixtures, двуязычные ссылки и diff:
  аудит, лог, результаты/хеши исходников.

В этих проверках ошибок не обнаружено. CLI-тесты требуют точного совпадения no-argument/help,
отсутствия строки завершения инспекции, прежних ошибок неверных аргументов и I/O failure для обоих
запусков справки через pipe, чей reader закрыт до запуска процесса. Прежние 72 designed CLI-случая
и 84 human-случая по-прежнему покрыты. Форматы вывода при переданном входе, wire-поведение, библиотеки,
Java-исходники и байты fixtures неизменны. EN/RU-инструкции и политика синхронизированы.

Это проверки автора, не независимое ревью. Release-сборки использовали настроенные каталоги;
в пользовательском Debug-каталоге пересобран только таргет инспектора. Полная Debug/ClangCL/sanitizer
матрица, новый Java capture и инъекции allocation failure для этой CLI-ветки не выполнялись.
Прежние доказательства остаются историческими. Коммит не создан.
