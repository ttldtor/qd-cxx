# Рефакторинг модели типов ради читаемости

[English version](TYPE-MODEL-REFACTOR.md). Английская версия является нормативной.

Исходный commit: `bfdeca0d6450533bc8ef1c5a9cd098d62039a375`, ветка `task/qdcxx-024-field-types`.
Дополнение по просьбе владельца: явно выразить базовую сериализацию и представление и не копировать
полные числовые ID в production-код, который использует эти типы. Поддержка типов и wire-поведение не расширены.

## Изменения и обоснование

- `SerialType` именует три реализованных базовых типа; `FieldRepresentation` — реализованные
  селекторы представления. Селекторы являются альтернативами, а не независимыми флагами.
- `SerialFieldType` сохраняет имена, базовый тип int32 и значения 2/8/10/40/56/72/88/120;
  определения теперь составлены из именованных компонентов. Входные raw ID остаются int32.
- Маски и функции извлечения сохраняют неизвестные старшие биты. Составление ID не проверяет
  допустимость пары. Проверка точного ID в `supportsSerialType` остаётся нормативной для схемы
  и binding; switch перечисляет каждый полный тип один раз без повторяющихся приведений/сравнений.
- Диагностическая схема tape использует общий enum полных типов вместо собственного списка чисел.
  Независимые числовые ожидания сохранены в conformance-тестах для обнаружения случайного изменения ID.
- Декодер/структура значений, владение, бюджеты, форматы вывода, Java-инструменты и эталоны неизменны.

Основание: [FIELD-TYPES](../../../../spec/encoding/FIELD-TYPES.ru.md), включая закреплённые Java-маски
и определения компонентов. Новых гипотез о Java-семантике или захватов нет.

## Историческая проверка автора

До реализации существующий MSVC Release `field_type_java_values` прошёл. После добавления нового
теста, но до production-изменений, сборка этой цели завершилась ошибками отсутствующих объявлений
`SerialType`, `FieldRepresentation` и функций. После реализации тест прошёл.

Новые проверки независимо проверяют все восемь полных ID и их компоненты, все 256 однобайтовых ID,
неизвестные старшие биты, знаковые границы, неподдерживаемые пары компонентов и constexpr-вычисление.
Существующие исчерпывающие проверки профилей (от -1 до 256), значений и Java fixtures сохранены.

Инкрементальная пересборка MSVC Release и все 25 наборов CTest прошли, включая отрицательные проверки
fixtures и прежние CLI-проверки tape/QTP. Три изменённых C++ файла прошли закреплённый Format pipeline.
Инкрементальная пересборка GCC Debug ASan+UBSan и все 25 наборов также прошли в WSL.
Production-сборка GCC Release (`BUILD_TESTING=OFF`, оба инспектора ON) успешно пересобрана.
Первая попытка использовать этот Linux-каталог из Windows CMake завершилась ошибкой пути
Linux-генератора в кэше; правильный запуск через WSL затем прошёл. Кэш ради обхода ошибки не переписывался.
Format с последующим неизменяющим Check прошли для всех трёх изменённых C++ файлов.

Три проверки упрощения без изменений файлов (повторное использование, качество, эффективность)
не нашли необходимых изменений в diff заголовка/теста. Автор также проверил замену enum в инструменте
и итоговый diff. Отдельный запуск `ce-code-review` не смог запустить ревьюера: достигнут лимит
агентских задач сессии, а операции освобождения среда не предоставляет. Завершение независимого ревью

в новой сессии остаётся открытым. Внешний CLI другой модели недоступен; внешняя задача не запускалась.
