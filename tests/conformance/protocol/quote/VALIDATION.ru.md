# Авторская валидация стандартного Quote

[English version](VALIDATION.md). Английская версия является основной.

QDCXX-022 реализована от HEAD `fa5a0b967e9c021e656846cdd3d6faee5faa4776` в ветке
`task/qdcxx-022-default-quote`. Проверки ниже выполнены 2026-09-22 UTC. Коммита и staging нет.
**Независимое ревью ожидается.** Это наблюдения автора/команды, а не независимо повторённое ревью.

Первичные авторские прогоны ниже исторические. Последующее исправление границы представления и
дополнения тестов имеют отдельный отчёт исправления ревью; повторное независимое ревью ожидается.

## Порядок доказательств и контракта

Первый runtime capture Java предшествовал EN/RU [контракту значений](../../../../spec/encoding/QUOTE-VALUES.ru.md)
и [контракту отображения/профиля](../../../../spec/protocol/DEFAULT-QUOTE.ru.md), а они — реализации C++.
Полная default DXFeedScheme неизменна: 331 запись, composite Quote ID 0, двенадцать int-слотов,
восемь логических полей 56/2/120. Исходный tape размером 326 байт содержит пять настоящих Quote через
реальные QuoteDelegate.putEvent → FileWriter → FileReader → QuoteDelegate.getEvent.
Сорок дополнительных построенных tapes — узкие production-parser пробы; это отдельные доказательства.

[Валидация Java](../../../fixtures/protocol/quote/VALIDATION.ru.md) содержит два совпавших чистых capture
всех 86 артефактов, девять отклонённых мутаций, неуспешный полный отрицательный Verify и последующий
успешный Verify исходного baseline, а также прежний tape Verify 22 артефактов в каждом из четырёх
чистых запусков. Итоговое авторское сравнение повторило строгую проверку capture A.
Это последнее сравнение не является пятой чистой Java-сборкой. Итоговые хеши инструментов и артефактов
A/B/Verify проверены по сохранённым metadata в аудите.

Configure/build logs сохраняют фактические массивы команд, начало/окончание UTC и exit codes;
версии компиляторов находятся в аудите. GCC sanitizers используют
`-fsanitize=address,undefined -fno-omit-frame-pointer`. Каталоги исходников прежнего закреплённого doctest
переданы явно; новая загрузка зависимости из сети не заявляется. Прежние Python-проверки продолжают
выполняться без изменений среди старых наборов. Новых Python-скриптов и зависимостей нет.
Сохраняется CMake deprecation warning о minimum-version закреплённого doctest; ошибки сборок/тестов не игнорировались.

Свежие отдельные проверки: примитивы, 3 случая / 7958 assertions;
tape, 6 случаев / 54163 assertions;
IO, 5 случаев / 109 assertions. [Покрытие](COVERAGE.ru.md) перечисляет конечный набор.
Все 41 исходных Java tapes сравниваются целиком/по одному/по семи байтам с проверкой порядка символов,
точных тегов/raw values, decimal text/bits и отображённых значений. CLI-тесты сравнивают реальный tape,
включая chunking, точные/недостаточные бюджеты, понятные human decimals, прежнюю/новую диагностику и help.
IO-тесты также отклоняют неверные профили схемы/вывода и форму Quote до работы с input/stdout.

Девять мутаций для C++ consumer отклонены, затем исходный baseline
прошёл. Пять мутаций примитивов также отклонены при разработке.
Промежуточные проверки выявили неверную кодировку синтетического пустого символа и отсутствие
проверки схемы/вывода; обе проблемы исправлены до итоговой матрицы выше.

Четыре production-комбинации MSVC Release с BUILD_TESTING=OFF прошли:
OFF/OFF, OFF/ON,
ON/OFF, ON/ON
(QTP option / tape option). В каждом каталоге нет _deps и поиска Python3 в cache;
итоговый аудит повторил эти проверки. Core/encoding/protocol/Quote не зависят от CLI IO.

## Форматирование, сохранность и передача

Закреплённые Uncrustify 0.83.0 → clang-format 20.1.8 Format и
итоговый Check прошли для 46 C++ файлов. Java wrapper Format/Check прошли
для 13 файлов с OpenJDK 23.0.2 и закреплённым google-java-format 1.36.1; изменён только новый QuoteOracle,
а итоговые хеши исходника/инструментов совпадают с metadata последнего полного Verify. См. валидацию Java выше.

Аудит проверил все 1393 прежних хеша fixtures/upstream.lock,
все 86 новых хешей артефактов A/B/Verify, четыре хеша oracle tools, trailing whitespace и относительные
ссылки изменённых/untracked Markdown, git diff --check и отдельно staged diff.
Индекс пуст. Во время завершения владелец создал параллельный коммит, продвинувший HEAD до
28f4cb0f5c63c9705eaa71df76a35e898b6eeb11; изменён только AGENTS.md (правила завершения и уже
написанный раздел границ Quote). Коммит сохранён; агент реализации коммитов не создавал.
Компилируемые исходники в нём не менялись, поэтому итоговая матрица остаётся актуальной.
Отслеживаемый прежний Python bytecode cache, пересозданный ранним тестовым
запуском, восстановлен побайтно; итоговые запуски отключали запись bytecode.

Три ограниченных внутренних прохода качества проверили повторное использование, ясность и эффективность.
Применены общие фиксированные имена полей Quote, удаление повторной канонизации NaN и устранение
повторного decimal-преобразования при подсчёте/записи вывода. Отдельный API скалярного отображения
и абстракция дескриптора двух фиксированных CLI-профилей не вводились: существующая проекция с пустым
символом избегает копии символа, а дополнительные публичные/структурные абстракции для этой задачи
не нужны. Эти проходы не заменяют независимое ревью.

ce-compound рассмотрен и пропущен: проектные обоснования уже сохранены в парных контрактах
значений/профиля и доказательствах проверок; отдельная заметка дублировала бы эти источники.
