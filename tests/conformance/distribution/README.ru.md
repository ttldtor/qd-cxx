# Приёмочная проверка раздачи

[English version](README.md).

Проверка запускает источник QTP, ретранслятор и два приложения-получателя. Она проверяет последнее значение Quote для позднего клиента, повторяющиеся TimeAndSale, снимок и удаление Order, сохранение общего спроса и отписку после ухода обоих клиентов. Процессы используют loopback и автоматически выбранные порты. При успехе выводится `PASS <режим>`. У каждого процесса отдельные журналы stdout и stderr. Для каждого прогона используйте новый каталог журналов.

Нужны [самостоятельная сборка примера из установленного SDK Feed](../../../examples/feed_distribution/README.ru.md), JDK 21 или новее и собранные классы Java QD из ревизии в [upstream.lock](../../../upstream.lock). Classpath должен включать модули QD и их зависимости времени выполнения. Для режима `native` достаточно классов драйвера и диспетчера процессов.

Команды сборки и запуска приведены в [английской версии](README.md). Используйте абсолютные пути и разделитель classpath `;` в Windows, `:` в Linux. `java-source` запускает издателя Java QD, `java-feed` запускает два получателя Java QD. Доступ к внешнему сервису и учётные данные не требуются. Встроенная справка доступна через `--help` и `--help-ru`.

Тесты издателя также проверяют переподключение, канонические Penta-байты подписок и изоляцию медленного клиента при ограниченном размере записи в сокет.
