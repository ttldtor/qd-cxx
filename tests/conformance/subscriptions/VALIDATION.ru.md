# Проверка эталона подписок

[English version](VALIDATION.md). Английская версия нормативная.

Выполнено 2026-10-31 на Windows NT 10.0.26340, PowerShell 7.6.9, CMake 4.4.2,
Zulu OpenJDK 1.8.0_422 с неизменёнными закреплёнными исходниками/классами из
[профиля захватов](../../fixtures/subscriptions/CAPTURES.ru.md). Готовые байты провайдеров
повторно использованы и сверены с доверенной квитанцией (1317 файлов, 14 корней модулей);
это не свежая сборка upstream. Фактическое объявление runtime остаётся QDS-UNKNOWN.

Два новых захвата итогового исходника побайтно совпали по всем 108 публичным артефактам,
392286 байт. Manifest покрывает каждый другой артефакт. Число случаев и строк:

| Компонент | Случаи | Строки наблюдений |
| --- | --- | --- |
| Wire | 22 | 2169 |
| Collectors | 21 | 2507 |
| Session | 32 | 899 |
| Всего | 75 | 5575 |

JDK 8 скомпилировал три инструмента и проверку ошибки вывода справки. Производственные
assertions выполнены для шести типов add/remove, requested layouts, коллекторов, дельт протокола,
всех масок heartbeat, capability readiness, клиентского login и серверной аутентификации.
Два диагностических ошибочных кадра сохраняют более узкую классификацию доказательств.

Запуск без аргументов и отдельная справка дали одинаковый stdout и пустой stderr без захватов.
CMake использует отдельный -DHELP=ON, Java — --help. Неверные Java-аргументы вернули 3.
Отказ от существующего выхода сохранил хеши деревьев. Внедрённая ошибка вывода справки
дала Wire 2, Collector 1 и Session 1; проверки Collector/Session сначала наблюдались
падающими, затем прошли после исправления обработки ошибки на итоговом исходнике.

Регрессии компаратора проверяют типизированный TSV, повтор ключей, покрытие случаев, provenance,
manifest, изменённые/пропавшие/лишние файлы, изменение бинарных байтов и пределы ресурсов.
Отказ хоста создать приватный junction явно учтён как пропуск reparse-теста, а не успешная
проверка отказа во время выполнения. Запрет reparse реализован до обхода.
Итоговая квитанция набора входит в доказательства интеграции; межплатформенный результат не выводится.

Закреплённый wrapper google-java-format 1.36.1 успешно выполнил Format, затем Check для всех
40 Java-исходников репозитория на отдельном JDK 25. Исходники C++, публичные заголовки и корневая
конфигурация сборки не менялись. Native CTest, sanitizers и Doxygen повторно не запускались:
здесь компилируются/выполняются инструменты Java и PowerShell, а входы Doxygen — заголовки.
Не заявляется Windows/Linux parity нативных подписок, выполнение Java на Linux, проверка
сокетов, TLS, DNS, внешнего endpoint, реальных учётных данных или полной бизнес-модели событий.

Команды воспроизведения, входы, конечные ограничения, коды ошибок и побочные действия даны в
[инструкции инструмента](../../../tools/upstream/subscription-oracle/README.ru.md).
Индексированные эталоны допускают точное офлайновое сравнение; различия исходников/провайдеров/
профиля протокола должны быть отражены, а не скрыты нормализацией.
