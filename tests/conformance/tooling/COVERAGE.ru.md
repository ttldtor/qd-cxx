# Покрытие переносимых средств разработки

[English version](COVERAGE.md). Английская версия является нормативной.

## Зафиксированные ожидания

Реализация начинается с `9b4f8ddf5786f71ac5f6d2305a0215a84b86b4b4`.
Исходные metadata фиксируют изначально чистые рабочее дерево/индекс и
защищённый перечень. [Машиночитаемая карта](coverage.json) фиксирует исходные 157 именованных обязательств и регрессии R5 stalled-open-console, stalled-log-fifo, stalled-stderr-diagnostic и same-session-process-group, а также регрессию R6 caller-temp-cache-preserved (всего 162)
и ответственные проверки. Это перечень требований приёмки, а не заявление о выполнении всех проверок.

[coverage.cmake](coverage.cmake) сравнивает точные идентификаторы, группы и уникальность
с независимым обязательным перечнем и требует непустого ответственного. Он отвергает удаление каждой записи, включая все
существующие 17 offline и 9 human меток мутаций. Один счётчик не позволяет принять подмену сценария.
Запуск: `cmake -DRUN=<private-test-directory> -P tests/conformance/tooling/coverage.cmake`.
Валидатор владеет временным подкаталогом с уникальным именем и при нормальном завершении удаляет только его.

## Характеризация до замены

Windows logger и
Linux logger характеризуют существующий PowerShell logger;
Linux-запуск включает `/dev/full`. Повтор Windows formatter
фиксирует 28 прежних setup/formatter-проверок. Эти запуски намеренно используют старый PowerShell-путь
вне нового дерева с запретом интерпретаторов; независимость от интерпретаторов ими не заявляется.
Сетевая ошибка первой попытки форматтера сохранена отдельно, а не переписана как успех.

R5 строже исторических доказательств logger: выход корневого процесса независимо запускает очистку
принадлежащих потомков за пять секунд, даже если унаследованные потоки остаются открыты.
Исторический успех не доказывает новое поведение. Native probe не использует production-библиотеки QD.
Заполненный stderr pipe без чтения не должен блокировать сообщение об ошибке launcher после очистки принадлежащих процессов. Диагностика использует нативную запись best-effort с ожиданием 100 миллисекунд и немедленным завершением процесса; поток записи владеет сообщением и не захватывает блокировки stdio.
Регрессия отдельной группы процессов внутри той же сессии проверяет, что смена группы потомком без выхода из принадлежащей сессии не позволяет избежать очистки.
Циклы `hold`/`running` останавливаются через 30 секунд, но запись вывода может блокироваться; внешние
проверки контракта владеют потомками, задают более короткие сроки и проверяют очистку, не полагаясь на probe timeout.

## Начальные доказательства bootstrap и ограничения

Успешный Windows bootstrap содержит UTC-границы фаз,
аргументы команд с длинами, коды configure/build и отдельные исходные потоки. Первоначально он собрал
только probe, пока logger ещё не был готов. Корневой CMake, doctest и готовый logger не использовались.
Первая попытка фиксирует запрет песочницы при поиске Windows SDK;
повтор использовал установленный Visual Studio 2022 с разрешённым доступом к SDK.
Намеренная ошибка отсутствующего source фиксирует configure exit 1;
после этой ошибки build не запускается. Отрицательные проверки покрытия
фиксируют все 157 отказов при удалении записи. Это только авторские проверки.

Начальный Linux bootstrap выполнил configure/build native probes
и доступных исходников logger через GCC. Этот запуск промежуточных исходников сообщает предупреждения
об устаревшем `u8path`; последующие профили проверяют итоговые исходники. Это не итоговая матрица
с запретом интерпретаторов.

Bootstrap — явное исключение журналирования первой сборки: он записывает исходные stdout/stderr и
UTC-начало/конец вместо времени каждой строки. Отдельные исходные потоки сохраняют байты, даже если
объединённое текстовое представление CMake отличается. Последующая приёмка использует собранный native
logger. Итоговые доказательства Windows/Linux-профилей относятся к парному отчёту validation.
macOS не проверена; изучение исходников не доказывает сборку или исполнение.
Независимая приёмка остаётся открытой.
