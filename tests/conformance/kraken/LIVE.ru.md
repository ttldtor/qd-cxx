# Проверка доставки живых котировок Kraken

[English version](LIVE.md).

Проверка запускает конечную публичную сессию BTC/USD и сопоставляет выход шлюза с данными двух независимых нативных процессов Feed. Цены и объёмы bid и ask сравниваются по точным сырым значениям wide decimal. У обоих клиентов проверяются символ и нулевые метаданные Quote по контракту шлюза. TICKER может объединять промежуточные обновления. Совпавшие котировки подтверждают доставку в пределах этого запуска.

## Запуск проверки

Используйте [руководство по сборке шлюза](../../../tools/kraken/README.ru.md), нативный клиент Quote из [руководства по офлайн-проверке](README.ru.md) и явно выбранный доверенный PEM для текущей цепочки Kraken. Для отдельной сборки нативного клиента задайте `-DORG_TTLDTOR_QDCXX_KRAKEN_TEST_PEER=OFF`. Этой сборке нужен только установленный SDK Feed. Запустите команды в PowerShell 7.2 или новее.

```powershell
./tests/conformance/kraken/Test-Live.ps1 -Help
./tests/conformance/kraken/Test-Live.ps1 `
  -Gateway ./stage/kraken/bin/qdcxx-kraken-gateway.exe `
  -Client ./build/kraken-native/qdcxx_kraken_quote_client.exe `
  -TrustPem ./kraken-ca.pem -Output ./.work/kraken-live
```

Для каждого запуска укажите новый каталог. Проверка запускает шлюз на автоматически выбранном порту IPv4 loopback. Оба клиента стартуют после сообщения шлюза о готовности порта. Проверка требует штатного завершения всех трёх процессов. Отчёт содержит совпавшую котировку и счётчики каждого клиента. Полные stdout и stderr остаются в выходном каталоге.
