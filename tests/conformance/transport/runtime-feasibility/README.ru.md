# Опциональные проекты проверки реализуемости runtime

[English version](README.md). Нормативный текст — английский.

Эти отдельные CMake-проекты проверяют механизмы [ADR-0006](../../../../docs/decisions/ADR-0006-live-runtime.ru.md).
Они не включены в обычную корневую сборку и не реализуют production transport.

- [DNS](dns/README.ru.md): закреплённый вариант c-ares с явной конфигурацией, управляемые вызывающим
  кодом UDP/TCP, отмена ожидающих запросов, квоты чтения/продолжение и отклонение конфигураций. По умолчанию OFF.
- [TCP/TLS](tls/README.ru.md): закреплённые SDK standalone Asio/OpenSSL, управляемые вызывающим кодом
  IOCP/epoll, ожидающие connect/read/write/handshake/shutdown, проверка тестовых identities и справки. По умолчанию OFF.

Зависимости получают явно, локально и с проверкой хешей из lock-файла каждого проекта. Исходные архивы
хранят отдельно от изменённых исходников. Глобальный менеджер пакетов, установка, изменения окружения
или firewall не требуются. DNS-патч и исходная лицензия находятся под Git; исходники/кеши сборок SDK,
сгенерированные тестовые ключи и полные журналы — локальные результаты. Следовать рецептам README
компонента, используя собственный каталог сборки. Рецепты Windows используют PowerShell и среду
разработчика MSVC x64; на обеих ОС применяются native CMake/CTest без зависимости от Python.
Для применения DNS-патча также нужен `patch`; он поставляется среди Unix-инструментов Git for Windows,
либо проверенный патч можно применить эквивалентным штатным инструментом.

[Контракт](../CONTRACTS.ru.md) и [валидация](../VALIDATION.ru.md) разделяют факты по исходникам,
выполненные проверки, области ресурсных ограничений и оставшуюся production-интеграцию. Успех прототипов
не доказывает наличие live QTP client, лимит всей памяти SDK или профиль внешнего провайдера.
