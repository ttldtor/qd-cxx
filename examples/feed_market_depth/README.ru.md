# Книги заявок для нескольких символов

[English version](README.md)

Пример подписывается на события Order источника NTV для AAPL и MSFT и выводит
зафиксированные заявки покупки и продажи отдельно для каждого символа.
Доступность NTV зависит от поставщика и прав доступа. Для совместимого локального источника используйте `--source DEFAULT`; `--source COMPOSITE` выбирает верхний уровень из Quote.

```text
cmake -S examples/feed_market_depth -B build/market-depth -G Ninja -DCMAKE_BUILD_TYPE=Release -DCMAKE_PREFIX_PATH=/path/to/qdcxx
cmake --build build/market-depth --config Release
build/market-depth/qdcxx-feed-market-depth --run
```

В Windows используйте консоль разработчика MSVC, соответствующую установленному SDK. Параметры описаны в `--help`. Пример использует обычный TCP и выполняет одну попытку соединения; он не переподключается и не восстанавливает книгу после разрыва. Незавершённые транзакции остаются внутри модели,
поэтому до их завершения вывод может повторять предыдущее состояние.

Успешное завершение требует непустую зафиксированную книгу по каждому символу,
активное соединение перед закрытием и завершённую локальную доставку. Сохранённая
при закрытии диагностика выводится отдельно.

При сборке из установленного каталога примера используйте `-S .`.
