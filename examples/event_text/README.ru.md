# Вывод события через std::cout

[English version](README.md). Английская версия является основной.

Полный пример публичного API создаёт собственный Quote, явно выбирает UTC и выводит возвращённую стандартную UTF-8 строку. Он не инициализирует timezone data, не читает файлы, не подключается и не меняет кодировку консоли. Отсутствующие бизнес-цены остаются NaN. Используются EventTextLimits{1024,4096,16384,65536} и отклонение malformed UTF-16.

Включите ORG_TTLDTOR_QDCXX_BUILD_EXAMPLES, соберите qdcxx_event_text_example и выполните qdcxx-event-text-example --run. Без аргументов и --help выводится одинаковая входонезависимая справка EN; --help-ru даёт справку RU. Код0: успех/справка, код1: ошибка форматирования/вывода, код2: неверные аргументы.

Для отдельного установленного приложения вызовите find_package(qdcxx CONFIG REQUIRED), подключите qdcxx_event_text и соберите [main.cpp](main.cpp). Для UTC-примера обычный пакет не требует backend. См. [руководство](../../docs/EVENT-TEXT.ru.md) об именованных контекстах и [контракт](../../spec/events/EVENT-TEXT.ru.md) о владении/бюджетах. Строка владеет байтами и доступна для лога после уничтожения события/контекста.
