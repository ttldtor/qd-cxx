# Локальные модели и инструменты клиента

[English version](README.md). Отдельное офлайн-приложение создаёт учебные Candle и Order, применяет их к моделям временного ряда и стакана и использует IPF collector, CFI и построитель опционных цепочек с учебным профилем акции. Эти данные не выдаются за данные источника. Для настоящих обновлений профилей отдельный пример live IPF устанавливается в `share/qdcxx/examples/ipf_live`, когда включён необязательный компонент IPF_LIVE и его зависимости transfer.

В установленном пакете qdcxx должны быть включены Feed и IPF:

```powershell
cmake -S . -B build "-DCMAKE_PREFIX_PATH=$prefix"
cmake --build build
ctest --test-dir build --output-on-failure
.\build\qdcxx-client-models.exe --run
```

Без аргументов, с `--help` или `--help-ru` выводится справка без входных данных. `--run` не обращается к сети и файлам и не создаёт worker. Код 0 означает успешные операции с моделями, 1 — отказ или ошибку, 2 — неверные аргументы. Модели и снимки владеют сохранёнными данными; приложение сериализует изменения модели.
