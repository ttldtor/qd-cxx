# Переподключение Feed

[English](README.md)

[Пример](main.cpp) подписывается на Quote, через десять секунд запрашивает
переподключение и продолжает использовать ту же подписку. Символы и обработчики
сохраняются; данные могут поступить с пропуском. Число попыток ограничено,
переподключение не увеличивает их запас. Используется обычный TCP. Главный поток
спит в обоих окнах приёма, пока рабочий поток доставляет события.
`Endpoint::create()` использует runtime библиотеки по умолчанию. Пример
дожидается закрытия endpoint, а библиотека дожидается рабочего потока при
завершении процесса.

Команды сборки и запуска приведены в [английской версии](README.md). Наличие
котировок зависит от доступности источника и прав. Пример не проверяет получение
данных в обеих эпохах соединения. Код 0 означает, что перед завершением endpoint
был подключён, но не подтверждает доставку данных или отсутствие пропусков.
Сохранённая диагностика выводится даже после успешного восстановления. Запуск
без аргументов показывает справку и не устанавливает соединение.

В каталоге установленного примера используйте `cmake -S .` с параметрами из
английской инструкции.
