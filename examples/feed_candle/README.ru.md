# Подписка на свечи

[English version](README.md).

[Пример](main.cpp) выбирает контракт HISTORY и подписывается на канонический символ Candle с включаемой нижней границей времени. Один обработчик выводит начальные свечи и последующие обновления. В выводе есть время, открытие, максимум, минимум и закрытие. Через десять секунд пример завершает работу endpoint.

Используйте [установленный Feed SDK](https://github.com/ttldtor/qd-cxx/blob/master/docs/CPP-BUILD.ru.md#public-feed-api-build-ru) с тем же компилятором и профилем. Команда для MSVC Release приведена в [английской инструкции](README.md).

Укажите QTP-источник с поддержкой HISTORY Candle для нужного символа и периода. Пример использует обычный TCP. Адрес и нижняя граница задаются в командной строке. [Запрос дневных свечей](https://github.com/ttldtor/qd-cxx/blob/master/examples/client_queries/README.ru.md) показывает отдельный разовый сценарий.

Команды сборки рассчитаны на корень исходников. В каталоге установленного примера используйте `cmake -S .` с теми же параметрами. Если копируете только каталог примера из исходников, добавьте в него `examples/feed_common/session.hpp`.

Общий код примеров задаёт окно приёма и дожидается закрытия endpoint. `ApiRuntime` дожидается своего рабочего потока при выходе из области видимости.

Пример принимает от 0 до 2147483647999 миллисекунд Unix.
